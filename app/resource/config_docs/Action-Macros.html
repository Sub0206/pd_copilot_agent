CoreSuite NAPC : Action Macros

Created by Susan Wilson, last modified on 06 Dec, 2019

Product Designer Users are able to configure Action Macros to manage the situation where the same set of Action Steps needs to be configured and used in several different Actions.

Action Macros should be invoked either by Standard Actions or by other Action Macros through a CoreSuite provided Internal Method. 

Although nothing in Product Designer will stop a User from calling an Action Macro from a View Item Button or on a Page load, it is not recommended because an Action Macro will not be able to change the navigation target if something was to fail within the macro.

The Web Page or View Item button will not be able to react to the return codes set by the macro.

 The configuration settings for Action Macros are the same as those for Actions.
