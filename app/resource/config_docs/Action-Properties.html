CoreSuite NAPC : Action Properties

Created by Susan Wilson, last modified on 06 Dec, 2019

Policy Actions can be divided into two groups; actions that support Views and those that do not. View Actions are specifically created to support the processing of a View; they provide Answer Options, specific Values, and validations of data found in a View. They also make available the XML that the View uses to process the View Items. The properties of the Policy Actions, Policy Steps, and Policy Step Outcomes will be different for Actions that support Views (View Actions) versus Actions that are not specifically created to support Views (Standard Actions).

Standard Actions can be used in numerous ways. They can be made available on the Policy Action Drop down such that a User can trigger them when they desire or they can also be called at the completion of a Web Page (configured by a Product Designer User). Finally, Standard Actions can also be invoked via a Web Service. This allows the same Action to be used online as well as via a Web Service.
