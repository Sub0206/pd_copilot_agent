Created by Susan Wilson, last modified on 06 Dec, 2019
PropertyValueDefinition / BehaviorApplicability
Triggered Action For Current ViewText: Maximum Length = 20 Characters

Indicates the name of the action to trigger if the value of this view item changes.

Note that this field will support the auto complete plugin to show available View Actions.

Literal on screen (to right of control):  Only supports View Actions

This field will also support the "Navigate" icon which will allow the user to save the current page content and navigate directly to the Policy Action Occurrence.  Note that the Navigation bar should change to show the Actions page context switch.

Applicable when View Type = Detail OR Updateable List

Optional
