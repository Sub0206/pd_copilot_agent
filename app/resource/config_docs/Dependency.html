CoreSuite NAPC : Dependency

Created by Susan Wilson, last modified on 10 Dec, 2019

Dependencies are used throughout the Product and Policy configuration sections of CoreSuite to specify conditional processing rules. They can be applied to Coverages, View Items, and Action Steps

CountNumber of answers that currently contain a value.  Does not count any answers that are not applicable or set to missing.

Distinct Count

Number of distinct answers that currently contain a value.  For example, if the Multi Value returned answers of PP, PP, and PU.  The Distinct Count would be 2.  Note:  Does not count any answers that are not applicable or set to missing. If an answer was not applicable on an occurrence (due to dependency), then it will not be counted in this function. 



Legacy Count

Total number of answers that contain a value and have not been filtered out via Multi Value dependency and existed within the context of the current transaction (including occurrences that were deleted on this transaction).  Does not count any answers that are not applicable or set to missing.  For example, if there existed 3 occurrences when the transaction was started and the user deleted an occurrence, then added another (and all occurrences had an answer for the question that is pointed to), the Legacy Count would be 4 (where as Count would be 3).  This count will NOT include occurrences that were added and then deleted within the same transaction.



Sum

The sum of the values returned in the Multi Value question (Non Numeric values will have an assumed value of 0).



Minimum

Will give the minimum value for answers that contain a value.  Does not include any answers that are not applicable or set to missing.  Note that if any of the values are text then zero is returned.  If the type is a date or date timestamp, then the earliest date/timestamp will be returned.



Maximum

Will give the maximum value for answers that contain a value.  Does not include any answers that are not applicable or set to missing.  Note that if the values are text, then zero is returned.  If the type is a date or date timestamp, then the latest date/timestamp will be returned.
