CoreSuite NAPC : Interface Views

Created by Susan Wilson on 25 Oct, 2019

Interfaces are composed of multiple views. Each view will detail the data that should considered during the processing of that interface.

Seq #Numeric: Maximum 5 DigitsSequences the Views within the List (sorted ascending)

Determines order in which views are processed on Account Manager

For Data Completeness Interfaces, Seq # drives the order in which the links to specific pages are presented to the user on the Missing / Invalid Info page 

Please note that when a Question appears in multiple Views within an Interface the lowest Seq# View definition for that element will determine the validation rules to be applied 

For the Rule-Reapplication Interfaces, the order of the Views determines how the Policy is re-processed. For example, the Vehicle Detail View should be Sequenced lower than the Coverage Grid Detail View because Vehicle Types drive the validate rules for Coverages

In general, use the order of the Web Pages to determine the order of the Views
