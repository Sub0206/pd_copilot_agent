CoreSuite NAPC : Interfaces

Created by Susan Wilson, last modified on 06 Dec, 2019

 

Interfaces in CoreSuite Policy define the data that needs to be passed into (via XML) or received back and validated from either an internal / external service or a CoreSuite Policy Internal Method, e.g. Rule Reapplication or Completeness Check. The interface specifies the specific data that should be included. Data not included in the interface will not be considered during processing. Additions, modifications and deletions to an interface are tracked by the Configuration Version.

The Interfaces link will only be shown to Product Designer Users with authority of 900 or above.
