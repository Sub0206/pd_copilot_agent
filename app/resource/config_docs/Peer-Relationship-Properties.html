CoreSuite NAPC : Peer Relationship Properties

Created by Susan Wilson, last modified on 10 Dec, 2019
PropertyValueDefinition / Behavior
Peer Inherit TypeDefault

Sets the initial answer value to this view item for the current product occurrence to the result of the peer inherit formula. 

Example: Set the Limit for Coverage B to 10% of the current Limit of Coverage A, but allow that value to be changed by the User (if desired).


Derived

Sets (and keeps in sync) the answer value to this question for the current product occurrence to the result of the peer inherit formula 

Example: Set the Limit for Coverage B to 10% of the current Limit of Coverage A, and keep the value for Coverage B in sync with any changes to the value for Coverage A. Users may not change a derived answer value.


Cap Value (numeric only)Prevents the answer value for this question on the current product occurrence to be greater than the result of the peer inherit formula.

Cap and Default (numeric only)Sets the initial answer value for this question on the current product occurrence to the result of the peer inherit formula and do not allow the answer value to be greater than the result of the peer inherit formula.

Floor Value (numeric only)Do not allow the answer value for this question on the current product occurrence to be less than the result of the peer inherits formula.

Floor and Default (numeric value)Set the initial answer value for this question on the current product occurrence to the result of the peer inherit formula and do not allow the answer value to be less than the result of the peer inherit formula.
Peer Occurrence(Peer Occurrence Name)The product occurrence from which the current product occurrence will get the answer value for this view item / question.
Peer Inherit Formula(User defined, syntax help available on hyperlink)The expression that will be evaluated to determine the value that will be used in conjunction with the Peer Inheritance Type to set (and perhaps constrain) the answer value for the current question on the current product occurrence.


To view Peer Relationship Properties:

Web Page => View => View Item => Version => Variation => Select Occurrence Ancestry => Peer Relationships Properties located at bottom of Edit screen below Determination Settings
