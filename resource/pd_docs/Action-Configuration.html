Locking Settings

Automatic (Default)

Disable Customer Locking

  • This property will instruct the Action on what Locking scenario should be applied for the duration of the Action execution.
  • AUTO represents the current pre-8.0.0.1 behavior where the current transaction is locked, MC locking is also acquired if necessary, and all Customers tied to the policy are also locked.
  • AUTO is the default value and the value assumed if no value is specified
  • DISABLECUST instructs the Action to lock only the policy transaction and MC where required.  No Customer locks will be acquired.
Applicable when Action Type = Standard Action OR View Action


Action Step Configuration


An Action Step is a single unit of work within an Action. Within an Action Step, the Product Designer User is able to configure one of the following functions:

  • Create XML, Use Created XML from prior step, Accept XML as input, or do not create/use any XML
  • Optionally apply an XSLT to transform the XML
  • Call a service (Web Service - URL, Web Service - EJB, or Adaptik Internal Method)
  • Optionally apply an XSLT to transform the XML returned (available only for Steps that support Detail View)
