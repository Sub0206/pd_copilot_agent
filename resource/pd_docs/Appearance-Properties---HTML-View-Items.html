Preview 
(button)
This button supports the display of the HTML in the HTML Text property in a processed form in a pop-up window. 
The pop-up window is modal and must be closed before any further activities can be performed in Product Designer. 
The content displayed in the pop-up window is derived from the current contents of the field which may reflect changes from what is persisted in the database for the View Item. 
The same error validation that is performed at Submit will be performed before a Preview. If any errors are found, the pop up message will be displayed and the Preview aborted.		Applicable only when the View Item Type is HTML


VI Placement


The View Item Placement tool will render any HTML View Items in a processed fashion so that they may be viewed in the context of the rest of the page layout. 

Errors/Warnings


On Submit of the page, the HTML content will be validated for the following conditions. If any of these conditions are found, the associated error message will be displayed in a pop-up window and the User will be prevented from leaving the page. Validation will end at the first error found, and only one error message will be presented. 

Non-well-formed HTMLAll HTML tags must be properly closed to insulate the rest of the page from being skewed by the contents of the HTML. 
Error Message: The HTML is not well-formed. Please check that all tags are properly closed.
HTML tag presentBecause the HTML will be integrated into the appropriate Account Manager web page, an HTML tag should not be present in the subordinate HTML. 
Error Message: An HTML View Item may not contain the <HTML> or <html> tag. Please remove that tag from the View Item Contents.
BODY tag presentThe Account Manager web page will already have a BODY tag present, and HTML will generate an error if more than one is present. 
Error Message: An HTML View Item may not contain the <BODY> or <body> tag. Please remove that tag from the View Item Contents.
HEAD tag presentThe Account Manager web page will already have a HEAD tag defined; the subordinate HTML in this View Item should not be defining another. 
Error Message: An HTML View Item may not contain the <HEAD> or <head> tag. Please remove that tag from the View Item Contents.
DIV tag presentHTML View Items will not be permitted to define divs on the page. 
Error Message: An HTML View Item may not contain the <DIV> or <div> tag. Please remove that tag from the View Item Contents.
FRAME tag presentHTML View Items will not be permitted to define frames on the page. 
Error Message: An HTML View Item may not contain the <FRAME> or <frame> tag. Please remove that tag from the View Item Contents.
IFRAME tag presentHTML View Items will not be permitted to define frames of any kind on the page. 
Error Message: An HTML View Item may not contain the <IFRAME> or <iframe> tag. Please remove that tag from the View Item Contents.
SCRIPT tag presentHTML View Items are not permitted to define script entries on the page. 
Error Message: An HTML View Item may not contain the <SCRIPT> or <script> tag. Please remove that tag from the View Item Contents.
XML tag presentHTML View Items are not permitted to use XML entries on the page. 
Error Message: An HTML View Item may not contain the <XML> or <xml> tag. Please remove that tag from the View Item Contents.
XSL tag presentHTML View Items are not permitted to use XSL entries on the page. 
Error Message: An HTML View Item may not contain the <XSL> or <xsl> tag. Please remove that tag from the View Item Contents.
FORM tag presentHTML View Items are not permitted to capture data items on the page. 
Error Message: An HTML View Item may not contain the <FORM> or <form> tag. Please remove that tag from the View Item Contents.


Additional HTML errors may be reported by the browser that is interpreting the HTML. Product Designer will only provide validation for the conditions listed above.

Style Settings

Style Settings will be applied to the HTML content similar to the way they are applied for Literals. However formatting can be changed from within the HTML, so specific instructions embedded in the HTML may override Style settings and/or style sheet formatting
