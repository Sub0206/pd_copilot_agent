General Settings

PropertyValueDefinition / BehaviorApplicability
Column Order(User defined)The order from the left margin of the list (relative to the other view items) in which this view item will be displayed as a column.Always applicable and required
Initial Sort DirectionAscendingThis column will be sorted in ascending order when the list is first displayedAlways applicable

DescendingThis column will be sorted in descending order when the list is first displayed
Initial Sort Sequence(User defined)The sort order, relative to other view items. For example, if a list should be sorted first by Vehicle Make, then by Vehicle Model then Vehicle Make would be assigned an initial sort sequence of "1" and Vehicle Model would have an initial sort order of "2".Always applicable
