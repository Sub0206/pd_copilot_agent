CoreSuite NAPC : Appearance Properties - Literal View Items

Created by Susan Wilson, last modified on 10 Dec, 2019

The Properties associated with a Literal View Item are defined the same as those for a Question View Item, however certain properties applicable for a Question View Item are not available for Literal view Item. Also, the Answer Settings and Action Settings tabs do not apply for a Literal View Item.
