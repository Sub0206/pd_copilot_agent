CoreSuite NAPC : Multi-Value Variables in Dependencies

Created by Susan Wilson on 25 Oct, 2019

INCLUDED IN DEPENDENCIES PAGE

PropertyValueDefinition / BehaviorApplicability
Multi-Value ContentCountNumber of answers that are currently applicableApplicable when the Entity question is a Multi-value question type.

Distinct CountNumber of distinct answers that are currently applicable. For example, if the Multi Value returned answers of PP, PP, and PU. The Distinct Count would be 2. Note: If an answer was not applicable on an occurrence (due to dependency), then it will not be counted in this function. But if the question were applicable, but not answered, then this would be counted.

Legacy CountTotal number of answers that have not been filtered out via Multi Value dependency and existed within context of the current transaction (including occurrences that were deleted on this transaction). For example, if there existed 3 occurrences when the transaction was started and the User deleted an occurrence, then added another (and all occurrences had an answer for the question that is pointed to), the Legacy Count would be 4 (where as Count would be 3). This count will NOT include occurrences that were added and then deleted within the same transaction.

SumThe sum of the values returned in the Multi Value question (Non Numeric values will have an assumed value of 0).

MinimumWill give the minimum value for applicable answers. Note that if the values are text, then no value will be returned. If the type is date or date timestamp, then the latest date/timestamp will be returned.

MaximumWill give the maximum value for applicable answers. Note that if the values are text, then no value will be returned. If the type is date or date timestamp, then the latest date/timestamp will be returned.
