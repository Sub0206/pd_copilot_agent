CoreSuite NAPC : Create New Policy via Import - (a.k.a. Gateway Import)

Created by Former user on Oct 25, 2019

Description

DescriptionThis method provides much the same functionality as Create New Policy but works primarily in memory as opposed to the database and as a result can create a policy faster than the other method, but with somewhat less flexibility. 
 
Updates to the new policy are queued in memory and not submitted to the database until a successful completion.
Supported Action TypeStandard 
ConstraintsNone 
Suggested DependenciesNone
NotesUpdates are committed to the database only when the return code from this method is 1, 2, 28 or 29. For any other return code, the updates are lost and no MC or CT is created. In a non-success case, configuring an Outcome to commit the changes will have no effect. The changes will still be abandoned.

 

XML Usage

This method requires Update XML to provide information to the new policy. XML- Use should be Accept XML for Update.

Attributes

This method requires a single attribute allows the configurator to use differing sets of Views to process upload versus online requests while marking the online Views as "visited" for impact and Rule Reapplication processing. If no additional Views need to be marked the Attribute must still be included with an empty value.
