CoreSuite NAPC : AccidentsViolationsListTemplate

Created by Susan Wilson on 25 Oct, 2019

 

Web Page Property files are used to control the settings required for the various Templates configured as Web Pages in PolicyWriter.

 

The Policy - Accidents and Violations List Template uses Custom List Properties and Custom Detail Properties that must be named and configured as follows:

Usage

emptyListMessageRequiredemptyListMessage=There are currently no Accidents or Violations associated with the Customer Grouping.Provides the empty list message that is displayed to the user when there are no occurrences in the list. 
operatorQTagOptionaloperatorQTag=30010_27Identifies the Question from the Conceptual Model that contains the Operator Link value that identifies a Customer as an Operator 
productGroupFilterCodesOptionalproductGroupFilterCodes=AUTO,HOMEIndicates which Policies should be included when finding other Policies that share the same Policy Location Address Unit (30000_100). Product Groups Codes contained in this property must match with the stored Product Group code on question 30000_1. If no codes are specified, then other Policies will not be considered when pre-filling the list of Customers for the page.Use only valid Product Group Code values (20000_1)
includeResidentCustomersIndOptionalincludeResidentCustomersInd=YIndicates if Customers that are not on the policy but share the same Address Unit as Question 30000_100 should be included in the Operator drop-down.Default=N
scrollingEnabledOptionalscrollingEnabled=YWhen set to Y and the number of occurrences for the entity is less than beginPagingThreshold, then the list should be in scrolling mode. If set to N, then the list is always shown in paging mode.Default=N
beginPagingThresholdOptionalbeginPagingThreshold=50Indicates the number of occurrences for the entity before paging is enabled (greater than or equal to) when scrollingEnabled=Y. Also indicates when filtering and sorting functionality is performed on the server vs on the client. If scrollingEnabled=N, then the paging section will not be displayed unless the number of entity occurrences surpasses this threshold OR the viewable area for the list cannot display the specified number of occurrences. Note that the maximum number this property can contain is 300. An application exception is given to the user if a higher number is specified.Default=200
detailDisplayOptionaldetailDisplay=OIndicates how the corresponding Detail Presentation should be displayed. When scrollingEnabled=Y, then only Main Body and Overlay is available. If scrollingEnabled=N, then all of the options are available.Main Body (MB) - replaces the list with the detail.

Below List (BL) - shows the detail below the list.

Overlay (O) - shows the detail in a modal overlay.

Default=O
disableListOnEditOptionaldisableListOnEdit=NIndicates if the list should be disabled when the detail area is open. This property is only used if detailDisplay=BL. Default value is Y if not specified.Default=Y
