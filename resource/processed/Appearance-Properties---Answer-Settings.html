Format

Formats are limited using a combination of Data Type (from CQU) and HTML input type for Detail and UPD views:

The following formats are available for Text Data Type and Text or Password Control Types:

  • US Zip Code
  • US Zip Code + 4
  • US Social Security #
  • US Social Security # - Multi
  • PHONE - (###)###-####
  • Phone - Multi
  • US Federal ID #
  • Number - Separated (comma/decimal)
  • Local Currency
  • Number - #########
  • Positive Number - #########
  • Credit Card - ####-####-####-####
  • Date - Local Standard
  • Date - Multi Local Standard
  • Date – Multi Local Dropdown Standard
  • MM/YYYY - ##-####
  • Year - YY OR YYYY
  • Timestamp - mm/dd/yyyy hh:mm AM|PM
  • Alpha Numeric
  • Policy Number - xxxxxxxxx-xxx-x
  • Vehicle Identification Number (VIN)
  • E Mail

The following formats are available for Integer Data Type and Text, Password Control Types:

  • US Social Security # - Multi
  • Phone - Multi
  • Number - Separated (comma/decimal)
  • Local Currency
  • Number - #########
  • Positive Number - #########

The following formats are available for Real Data Type and Text, Password Control Types

  • Number - Separated (comma/decimal)
  • Local Currency

The following formats are available for Date Data Type and Text, Password, Text (TEL) Control Types:

  • Date - Local Standard
  • Date - Multi Local Standard
  • Date – Multi Local Dropdown Standard

The following formats are available for Timestamp and Text Control:

  • Timestamp mm/dd/yyyy hh:mm AM|PM

The following formats are available for Year and Text, Password, Text (TEL) Controls:

  • Year - YY OR YYYY

The following formats are available for TEL and Text Data Types:

  • US Zip Code
  • US Zip Code + 4
  • US Social Security #
  • US Social Security # - Multi
  • PHONE - (###)###-####
  • Phone - Multi
  • US Federal ID #
  • Credit Card - ####-####-####-####
  • Date - Local Standard
  • Date - Multi Local Standard
  • Date – Multi Local Dropdown Standard
  • MM/YYYY - ##-####
  • Year - YY OR YYYY

The following formats are available for Text (TEL) and Integer Data Types:

  • Year - YY OR YYYY

The following formats are available for Text Data Types and Email Control Type:

  • Email

The following formats are available for Text,  Hyperlink, Rich Text, Rich Text CK Editor Data Types and Text Area Control Type:

  • Alpha Numeric

The following formats are available for Canadian Postal code:

  • ANANAN where A is alphabetical and N is numeric

Note there are no formats currently available for the Text (URL) and Text (NUM) control type.

For a List View, the following formats should be shown:

  • Number - Separated (comma/decimal)
  • Local Currency
  • Date - Local Standard
