CoreSuite NAPC : ContractTransactionListTemplate

Created by Susan Wilson on 25 Oct, 2019

 

Web Page Property files are used to control the settings required for the various Templates configured as Web Pages in PolicyWriter.

 

The Policy - Transaction List Template uses Custom List Properties and Custom Detail Properties that must be named and configured as follows:

ContractTransactionList.properties
Property Parameter
Usage
Example Values
Description
Comments
presentationTypeRequiredpresentationType=ContractTransactionList  
emptyListMessageRequiredemptyListMessage=There are currently no transactionsProvides the empty list message that is displayed to the user 
doubleClickActionOptionaldoubleClickAction=continueIndicates the button that should be clicked for the user if they double click a rowDefault=edit
deleteContractTransactionActionOptionaldeleteContractTransactionAction=deleteTransactionAction to be called when Purge button is clicked from the list. 
backOutContractTransactionActionOptionalbackOutContractTransactionAction=backoutTransactionAction to be called when Rescind button is clicked from the list. 
backOutContractTransactionViewOptionalA valid configured Policy Entity (30000) Detail View

If a non-null value is provided, the Contract Transaction List page will invoke the identified Policy Entity Detail View in an overlay and allow the user to perform any updates or activities the View supports.

The View will always be rendered in an overlay that will be editable even on an issued transaction.
 

If the View is not found or not affiliated with the Policy entity an error will be produced in a confirmation box and the user will be returned to the underlying page.		 
unloadTransactionActionOptionalunloadTransactionAction=unloadTransactionAction to be called when Edit button is clicked from the list when focus is moved from one transaction to another. 
unloadVersionActionOptionalunloadTransactionAction=unloadVersionAction to be called when Edit button is clicked from the list when focus is moved from one version to another.
