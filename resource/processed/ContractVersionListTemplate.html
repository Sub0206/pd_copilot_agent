CoreSuite NAPC : ContractVersionListTemplate

Created by Susan Wilson on 25 Oct, 2019

Web Page Property files are used to control the settings required for the various Templates configured as Web Pages in PolicyWriter.

 

The Policy - Transaction Version List Template uses Custom List Properties and Custom Detail Properties that must be named and configured as follows:
