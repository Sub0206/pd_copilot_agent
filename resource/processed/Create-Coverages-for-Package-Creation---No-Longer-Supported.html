CoreSuite NAPC : Create Coverages for Package Creation - No Longer Supported

Created by Former user on Oct 25, 2019

Description

DescriptionThis method uses a Rule ReApplication against the entire policy transaction identified by the current context to add Coverages from a predefined Coverage Package to the current policy transaction. The method uses a set of Views defined in an Interface to apply the configured rules from the Views to the policy transaction.  After the Rule ReApplication has completed, the Coverage Package Code Question (30000-133) is reset to null.
Supported Action TypeStandard 
ConstraintsMust be executed from within a Policy Transaction context. 
Suggested DependenciesNone
NotesThis method is not used by itself as an action, but as a step in a more complex Policy Action that is one aspect of the Coverage Package Creation feature of PolicyWriter.

XML Usage

None
