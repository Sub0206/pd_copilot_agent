CoreSuite NAPC : Create Travelers Auto Coverage Packages

Created by Former user on Oct 25, 2019

Description

DescriptionThis function is used to remove any remaining versions of the quote or application and create new versions that conform to a specific set of Coverage packages using the following steps:   It accepts three attributes. The first defines which question on Policy is the link to the Product Coverage Package entity (20105). The second defines which package (version) should be in context upon completion. The third is the Rate action macro to call for each version.
  1. Mark all versions for the current Policy for removal (note that this should not need to be done as the versions should be been removed before this action was called.
  2. Retrieve the list of Product Coverage Package occurrences (20105) using the linked question passed as Attribute 1 of the Product Action Step. For each occurrence that is applicable, perform the following:
    • Using the last version in context, create a new version (not copying vehicle covs OR Contract answers from CPOL_FOR_COV_DT_2.
    • Using the Code question for the occurrence, update the Coverage Package question (30000_1535 which was passed via the Product Action Step).
    • Populate the Description question (30000_33) with the Coverage Package literal.
    • Process the CPOL_FOR_COV_DT_2 view (re-populating the answers for the Coverage Package).
    • For each vehicle, auto-select the coverages that are marked for Selection default for the Coverage Package (coverage package is used to find appropriate exception factor for Product Coverages).
    • Call the Rating Action which will call the Gateway for the quote version (passed as third Product Step Attribute).
  3. When all versions have completed the rating step, display the Your Quote page putting the "Regular" version in context (second attribute passed for the Product Action Step.
ConstraintsMust be executed from within a Policy Transaction context. 
Suggested DependenciesNone 
NotesThis method is specific to Travelers PL Auto.
