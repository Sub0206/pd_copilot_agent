CoreSuite NAPC : Create Travelers Custom Auto Version

Created by Former user on Oct 25, 2019

Description

DescriptionThis method is used to create a Travelers-specific customized version based upon the user's changes to the page from which the action is invoked. It will perform the following Steps:
  • If there exists a Custom Quote version, then use this version to make the following updates:
    • Use the contents from the top policy view (CPOL_FOR_COV_DT_2) as defined by the property file to update the equivalent questions on the Custom version.
    • Delete all of the existing vehicle coverages on the Custom Version.
    • Add the vehicle coverages as defined on the screen (coverage type = Primary).
    • Add the vehicle coverages based upon answers selected from top policy view (coverage type = secondary).
    • Call the Rating Action which will call the Gateway for the quote version (passed as second Product Step Attribute).
    • Display Your Quote page with this version in context.
  • If there does not exist a Custom Quote Version then:
    • Using the current version, create a new version.
    • Delete the Policy Answer for the Coverage Package (first Product Step attribute will supply Q-tag).
    • Update Q_30000_33 with "Custom".
    • Use the contents from the top policy view (CPOL_FOR_COV_DT_2) as defined by the property file, update the equivalent questions on the Custom version.
    • Delete all of the existing vehicle coverages on the Custom Version.
    • Add the vehicle coverages as defined on the screen (coverage type = Primary).
    • Add the vehicle coverages based upon answers selected from top policy view (coverage type = secondary).
    • Call the Rating Action which will call the Gateway for the quote version (passed as second Product Step Attribute).
    • Display Your Quote page with the Custom version in context.
ConstraintsNone 
Suggested DependenciesNone
