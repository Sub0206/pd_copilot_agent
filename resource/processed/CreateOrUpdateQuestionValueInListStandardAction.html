CoreSuite NAPC : CreateOrUpdateQuestionValueInListStandardAction

Created by Jagadish Rotti, last modified on Jul 25, 2022

Add Update Questions in OOS Transaction List

Description

This method will update existing contract answers, or create new ones. If a Contract Answer does not exist already, then a new one will be created using the base Question properties for Enforce Stage. If the entity referred to is not policy, then every occurrence of the entity type that exists will be updated.

If the MC-ID in context is part of an OOS transaction, then all transactions that are part of the OOS transaction list will be updated.
 
A repeating group of attributes will be accepted for this method. Each attribute will specify a question and the value that should be applied to that question.
 
Enforce Stage on the answer is copied from the existing answer or base Question Properties if no Contract Answer exists and used with the updated value.

Supported Action Type

Standard

Constraints

Must be executed from within a Policy Transaction context. 

Note that the following Questions should not be used:

  • Guest Questions are not supported with this method.  Only the host question should be updated via this method. 
  • Customer Link Questions.
  • Secondary Parent Questions.
  • Multi-Value Questions
  • Policy Facts
  • Derived Question (Answer Source = Derived)

Suggested Dependencies

None

Notes

If this method is used to update a Linked Question or a Question that uses Answer Options, it is suggested it be followed by a Rule Reapplication or Upload Step that processes those same Questions within the context of a View.  This is suggested because the method sets the Contract Answer value and attempts to set the appropriate literal (note that if the literal is changed via exception or versioning, the detail view is not processed which means it is possible the incorrect literal is set).  Rule Reapplication or Upload will execute the view and set the correct literal for the question.

If the Step Attribute Value is "CurrentDate()",  or "CurrentDateTime()" the current date or timestamp is used to create the answer value.

Also, policy level questions can be used as a source of the answer to be set.  If a value of Q_30000_## is specified, then the value of the specified question (and is related information such as literal) will be copied.

None
