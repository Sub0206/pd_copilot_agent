Customer Detail Properties

The Standard Customer Detail Properties are defined below:

individualCustomerRequiredAddressType

  • Always applicable 

  • Optional 

Valid Customer Address Type Value 

  • This property provides the Individual Customer Address Type value to be used for the Individual Customer on the page. 

  • If the property is not provided or has no value, the installation property’s value or the system default will be used. 

  • If the property does not contain a valid value for the installation, HOME will be used


leCustomerDetailAddressType

  • Always applicable 

  • Optional

Valid Customer Address Type Value

  • This property provides the Legal Entity Customer Address Type value to be used for the page. 

  • If the property is not provided or has no value, the installation property or the system default will be used. 

  • If the property does not contain a valid value for the installation, CORPHQ will also be used
