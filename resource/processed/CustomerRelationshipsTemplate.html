productGroupFilterCodesOptionalValid Product Group Code values (20000_1)
Example:
productGroupFilterCodes=AUTO:AUTO,HOME		HOME:HOME|UMBRELLA:AUTO, HOME, BOAT|BOAT:Indicates which Policies should be included when finding other Policies that share the same Policy Location Address Unit (30000_100). A Product Group Code will be by a colon followed by the Product Group codes that should be included. If Product Group code is not accounted for OR is given, but the filter Product Group codes are not specified, then only the current policy will be used to retrieve customers. If Product Group Filter codes are given who's answer values match the value stored in question 30000_1 will be retrieved. Using the example to the left, for an AUTO policy, only other AUTO and HOME policies will be used to find other Customers. If there were UMBRELLA or BOAT policies that contained other customers, they would not be included in the list. For a BOAT policy, no other policies will be retrieved because there are not any Product Group filters listed. 
primaryCustomerProtectionUserCodesOptionalValid User Codes from the Authorization XML.
Example:
primaryCustomerProtectionUserCodes=A1234,B22321		Indicates which user codes are allowed to change the Primary Customer field. If the User's Authorization XML does NOT contain one of the codes listed, then the field will be protected. If no codes are listed, then an online user will NOT be able to change the Primary Customer. 
exitServiceErrorMessageOptionalError message to be displayed to the user if the exit service call fails during submit of the page.

If null, or not specified, no error message will be displayed.
