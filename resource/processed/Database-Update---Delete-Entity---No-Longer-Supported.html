CoreSuite NAPC : Database Update - Delete Entity - No Longer Supported

Created by Former user on Oct 25, 2019

Description

DescriptionThis function is used to delete a single specified Occurrence (e.g. coverage or endorsement) from the current policy transaction in context using an occurrence identifier value to identify the occurrence. If the specified occurrence does not exist, then processing continues without any error.
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesThere is hard-coded logic that restricts this method's use to a select set of entities.

 

Attributes

The Attributes must be configured in the order listed below.
Code
Value
Type
Description
BTAGValid numeric Entity IdentifierStringProvides the entity type identification for the occurrence to be deleted.
QTAGValid Question Sequence NumberStringQuestion Sequence Number for the question to be used to identify the occurrence to update. Only the Question Sequence Number should be supplied, so for example if the question was Coverage Attachment Level on Policy (30000-8) the value for this attribute would be simply 8.   Must correspond to the question identified as an occurrence identifier.
CODE StringProvides the value for the specific question which will determine the correct occurrence to delete.

Return Codes

Return Code
Description
1Successful Delete.
2Item was not found. No Delete.
3Failure - No MC, CT, Version in context
-1Unspecified Failure
