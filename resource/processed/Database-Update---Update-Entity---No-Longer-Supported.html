CoreSuite NAPC : Database Update - Update Entity - No Longer Supported

Created by Former user on Oct 25, 2019

Description

DescriptionThis function is used to update a specific occurrence (e.g. coverage or endorsement) on a policy by setting the values of the questions on the specified View to the desired values.
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesThere is hard-coded logic that restricts this method's use to a select set of entities.

 

XML Usage

None

Attributes

The Attributes must be configured in the relative order in which they appear in the table below.
Code
Value
Type
Description
BTAGValid Entity Type IdentifierStringIdentifier for the Entity type to be updated.
VTAGValid View IdentifierStringIdentifier for the View to be used to receive the update.
QSEQValid Question Sequence NumberStringQuestion Sequence Number for the question to be used to identify the occurrence to update. Only the Question Sequence Number should be supplied, so for example if the question was Coverage Attachment Level on Policy (30000-8) the value for this attribute would be simply 8.   Must correspond to the question identified as an occurrence identifier.
CODEValue for QSEQ QuestionStringValue to be used to in the occurrence identifier specified above. [Question Number with BTAG as prefix] Value to be set String This parameter repeats for each question to be created on the entity being added. The Q-tag of the question appears in the Code field, and the Value specifies the value the question should be set to.   If DEFAULT is specified in the value field the defined default value for the question will be used.   If the value specified is not valid per the rules defined in the view, then the mismatch remedy for the question is used to provide a valid value.
