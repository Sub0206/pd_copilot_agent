Delete Occurrences (Standard Action Only)

DescriptionDeletes all occurrences of the specified entity types from the transaction in context using time dimensioning so that the deletions will show in generated XML and as changes on the policy transaction.
Supported Action TypeStandard
ConstraintsMust be in the context of a policy transaction.
Suggested DependenciesNone
NotesNone

 

XML Usage

None

Attributes

Each Entity type to be deleted is configured as a separate Attribute.

Return Codes

Return Code
Description
1Success
2Failure - No MC, CT, Version in context
-1Unspecified Failure

 

Implementation Example

Action

Trx_OCC_DELETES (Delete all occurs of some entities)
