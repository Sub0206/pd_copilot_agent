Delete Question Value (Standard Action Only)

DescriptionDeletes the Question Answer for the question(s) specified as an Attribute of the associated Step. The method will delete all instances of the answer on all occurrences of the associated entity type, and if an answer does not exist on an individual occurrence no error will be returned.
Supported Action TypeStandard
ConstraintsMust be executed from within the context of a policy transaction.
Suggested DependenciesNone
NotesNone

 

XML Usage

None

Attributes

The attributes identify the questions whose answers should be deleted where the code includes the Q-tag in the format Q_[B-tag]_[Q-seq].

Return Codes

Return Code
Description
1Delete Successful
2Failure - No MC, CT, Version in context
3Unspecified failure (cannot update DB, etc.)
-1Unspecified Failure
