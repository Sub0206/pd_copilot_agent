CoreSuite NAPC : DetailPresentationTemplate

Created by Susan Wilson, last modified on 05 Dec, 2019
The Detail Template is used to view or edit the details of a single occurrence of the designated entity type. This Template requires an occurrence to have been previously selected and placed into context from another Template, such as after choosing a policy from the search screen. Typical examples include pages that support collecting Billing or Underwriting information for the policy as a whole.

 

 

 

Web Page Property files are used to control the settings required for the various Templates configured as Web Pages.
