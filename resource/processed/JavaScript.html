Call JavaScript (Standard Action Only)

DescriptionThis method allows the Account Manager client to invoke a JavaScript method or function that lies outside PolicyWriter such as in a portal or other enveloping context.
Supported Action TypeStandard
ConstraintsNone
Suggested DependenciesNone
NotesNone

 

Attributes

The Call JavaScript method calls a JavaScript function and uses Attributes to pass parameters to that function.  The function being called will typically be project specific to perform a certain task within the page and should not typically be used to call internal Adaptik JavaScript functions. The Attributes required will vary based on the JavaScript being called.


If the configurator wants to send the Policy XML to the JavaScript, then the user can configure the step that calls the method such that XML is generated. The XML-use attribute should be set to "Generate from DB" or "Re-use from Prior Step" and the other appropriate XML attributes should be set. This will cause an XML to be created and sent as the first argument to the JavaScript.

If the user needs to send additional arguments, then the Action Step Attributes can be used. For each attribute defined, one argument will be added. The order will be determined by the Sequence number of the Attribute. The Value will contain either a constant or a Policy entity Q-tag (denoted with a format of "Q_30000_#") or a supported function such as CurrentDate(). For example, if the configurator needed to set up an Action Step that called the JavaScript JavaScriptName(XYZ) where XYZ is the value of Q_30000_34, an Attribute would be configured that sends the value of question 30000_34 as the first and only parameter.

Note that if the XML were to be generated that would then create an argument before XYZ that contains the XML.
