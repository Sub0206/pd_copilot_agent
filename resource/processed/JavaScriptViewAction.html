CoreSuite NAPC : JavaScriptViewAction

Created by Former user on Oct 25, 2019

Call JavaScript (View Action Only)

DescriptionThis method will call a JavaScript method within context of a Detail or Updateable List View. The JavaScript name is specified on the Product Action Step page.
Supported Action TypeView Action
ConstraintsMust be executed from within a data capture page context (Detail View or Updateable List View). There can be only ONE step inside of the Action.
Suggested DependenciesNone
NotesThe entire client side model will be made available to the JavaScript. If there is data needed that is in the ancestry of the policy and there is not a view on the page that contains that information, then a Guest Question must be configured so that the client model will have the data for the JavaScript method.

 

XML Usage

None. The client model in context will be used in lieu of a generated XML.

Attributes

None. All data that is use as input to the JavaScript method should be contained in the client side model.

Return Codes

Return Codes Not Currently Supported
