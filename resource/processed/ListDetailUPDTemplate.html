CoreSuite NAPC : ListDetailUPDTemplate

Created by Susan Wilson, last modified on 20 Nov, 2019

The List + Detail + Updateable List Template allows a user to click an Add/Edit button from a List which will allow them to capture the detail of the occurrence (of the list) as well as children occurrences via an updateable list.  Note that via configuration, the Updatable List may be optional. 

The List + Detail + Updateable List Template uses the Standard List Properties, the Standard Detail Properties, and the Standard Updateable List Properties.

List Properties

Note that other modes and extensions of the list (Parent Child mode, ParentSelectionList, PolicyCustomerListPresentation, System Messages List, System Message Child list, Propagate List, etc) will NOT be able to launch a Detail + Updateable List.

Detail Properties

Note that only the deleteParent property will NOT be supported with this template.  The user may remove the occurrence directly via the list Delete button.  Also, this template will NOT support a Multi-Detail paradigm where there is more than one Detail unit that captures information for the occurrence presented in the list.  For example, the List launches Detail 1, upon submit, a Detail + Updateable List could not be presented BEFORE the list is returned to.
