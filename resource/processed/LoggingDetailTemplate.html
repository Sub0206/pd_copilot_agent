CoreSuite NAPC : LoggingDetailTemplate

Created by Susan Wilson on 25 Oct, 2019

Web Page Property files are used to control the settings required for the various Templates configured as Web Pages in PolicyWriter.

 

The Policy - Logging Template uses Custom Detail Properties that must be named and configured as follows:

LoggingDetail.properties
Property Parameter
Usage
Example Values
Description
Comments
Presentation TypeRequiredpresentationType=LoggingPresentation  
ViewNameRequiredValid Logging Detail View V-Tag
Example:
ViewName=LOGGING_DT		Provides the Logging Detail View that will be used to supply the presentation information for the presentation type.
