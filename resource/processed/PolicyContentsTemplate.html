CoreSuite NAPC : PolicyContentsTemplate

Created by Susan Wilson on 25 Oct, 2019

Web Page Property files are used to control the settings required for the various Templates configured as Web Pages in PolicyWriter.

The Policy - Contents Template uses Custom Policy Contents Properties that must be named and configured as follows:

PolicyContents.properties
Property Parameter
Usage
Example Values
Description
Comments
presentationTypeRequiredPolicyContents
Example:
presentationType=PolicyContents		Provides the Presentation type that is being instantiated 
autoOpenNodesOptionalY, N
Example:
autoOpenNodes=N		Default assumed 'N' if not present.
A value of 'Y' will cause all level of detail to initially show.
Any other value will cause only the first level of detail below policy to initially show.		 
enableStyleIdentifierOptionalY, N
Example:
enableStyleIdentifier=Y		Default assumed 'N' if not present.
A value of 'Y' will cause identifier values to display in different color than the associated literals.
Any other value will cause the line items to display in monochrome.		 
chunkSizeOptionalValid Positive Integer
Example:
chunkSize=700		Indicates the number of children occurrences to load on the page at a time with each request.
