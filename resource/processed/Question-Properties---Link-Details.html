Linked To

List of Entities from Reference,  Product and Customer (if Customer enabled).

Format:  Entity Name - B-tag i.e. Country - 10000		Establishes a link to a Reference, Product or Customer Occurrence

Note that if the user changes the linked to Customer Occurrence, all other questions that use this link will NOT be automatically adjusted. The Configurator must manually adjust each of these questions.

Stored in Question Relation B-TAG or TARGET-B-TAG where Type = L.		Always applicable and required

Restrict Reference List?Yes
No (Default)		Indicates if the Answer options of this question should subset the full reference list of occurrencesApplicable and required when B-tag of Linked To is a Reference Entity.
Refine Link Choices ByList of Questions that can be used to restrict the values of the Linked Entity.  Only Questions that link to Ancestors of the Entity of the Linked To question.  For example, if Linked To linked to State, then policy questions that point to Country (State's parent) should be shown.
Format:  Question Name - Q-tag i.e. Country - 30000_4		Specifies another linked question which should be used to filter the answers available for this question. The question specified here should refer to an ancestor of the linked to entity e.g. List of states could be refined by Country.

Applicable if B-tag of Linked To has an Entity Ancestry.

Optional

Data Source for Exception Factor 

Drop Down

List of Questions that point to the Exception Factor B-tag.  Note that the literal shows the B Name of the Exception Factors.  For example, Country, State, Product Offering.  For each factor, there will be one question.

Can Customer Occurrence be Added?Yes
No (Default)
  • Indicates if the associated Link can be used in Add Mode without the Customer or Address Rolodex to capture data for a new corresponding occurrence as part of Detail View processing.
  • No is the default answer for the page.
  • If no answer is supplied for this property, No (N) is assumed for backward compatibility.
  • This property is supported only in Detail View and Updateable List processing as well as standard Upload.  It is not supported in Trusted Source Upload.
  • If B-tag = 40002, 40003, then this value should be set to Yes and Protected.
Applicable if Linked To is Customer (40000), Address (40001) or any other Customer entity 40000 or higher.
