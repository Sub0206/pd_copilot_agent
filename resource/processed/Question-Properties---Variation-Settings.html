Format:  Entity Name - B-tag i.e. Product Group - 20000		Product Configuration Entity by which this Question's properties vary. For example, Product Coverage would be selected if the question properties vary by coverage. Select Product Group if question properties vary based on dependencies rather than Product Entity occurrences. 
This question also must be answered to specify for which policy entity answer options may vary. For example, if answer options for this question vary by Program Offering, this property would be sent to "Program Offering" and the Product Designer User would be prompted to specify the Program Offering when working with answer options for view items based on this question.		Applicable and required when May Question Properties Vary? = Yes

Current milliseconds from the application server.  Can be used as a unique ID.

Current Date/Time from the application server in yyyy-MM-dd HH:mm:ss.SSS format (uses Override System Date).

Current Date/Time from the application server in MM/dd/yyyy HH:mm format (uses Override System Date).

Current Date from the application server in MM/dd/yyyy format (uses Override System Date).

USER

Current User ID.

 SEQNO

Max value + 1 for the given Question in this MC, CT, Version in context.

LOCATION

Max value + 1 for the given question on this policy (MC) - Ignores Time dimension just does a max value (includes deleted Answers).

SEQRECYCLE

Max value + 1 for the given question in this MC, CT, Version if there is not a "gap".  Gaps are filled first.  For example, if answers 1, 3, 4 exist, then 2 will be assigned. If 1, 2, 3, 4 exist, then 5 will be assigned.

 

If none of the reserved words itemized above are used, then the value typed will be used to look for a Database sequence table that will give the next unique number (across all policies).		Always Applicable and optional
