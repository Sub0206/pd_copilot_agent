CoreSuite NAPC : StoreXMLInReportingTable

Created by Jagadish Rotti, last modified on Jun 02, 2023

Store XML in Reporting Table

Description 

This new method will take the XML provided to the Step and after any Forward XSL processes it, stores it in the table/column that are specified as Step Attributes to the method.

 

All calls to this method will add or update a record to the table, there is no option to delete the XML CLOB except for deletion of the Contract Answer.  The code will add a record when the occurrence does not already exist, otherwise if the occurrence exists the XML CLOB will be updated. 
 
This method is supported in both an online context and via the webservice gateway. When used in an online context the Step should generate the XML to be stored. When used via the webservice gateway the configuration could be set to Accept Input XML and then transform and store it. 

Supported Action Type 

Standard 

Constraints 

Must be executed from within a PolicyPro or BillingPro occurrence context. 

Suggested Dependencies 

None 

Notes 

None


XML Usage 

Generate from DB, Accept XML for Update, or Reuse XML from Prior Step are all supported options for the XML required for this method.
