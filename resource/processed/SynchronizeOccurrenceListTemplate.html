CoreSuite NAPC : SynchronizeOccurrenceListTemplate

Created by Susan Wilson, last modified on 20 Nov, 2019



Web Page Property files are used to control the settings required for the various Templates configured as Web Pages.

The Synchronize Occurrence List extends the ListPresentation Properties with the following required properties that must be named and configured as follows:

 

Property Name

Values

Behavior

Required?

presentationType

Must be set to SynchronizeOccurrenceListPresentation

Example: presentationType = SynchronizeOccurrenceListPresentation

 

Indicates that the presentation type to be used.  Extends ListPresentation with the noted exceptions below.

Yes

viewName

Valid List View that belongs to the same Entity as the list that launched the Synchronize Overlay.

Example: viewName= formsLT

Provides the List View that will be used to capture the policy occurrences that should be synchronized.

Yes

synchronizeVersionSearchDetailTarget

Valid Properties file name

Example: synchronizeVersionSearchDetailTarget = synchronizeSearchVersionsDetailProperties

Provides the properties file name that will be used to search for the available Contract Transaction Versions.

Yes

synchronizeVersionSearchResultsListTarget

Valid Properties file name

Example: synchronizeVersionSearchResultsListTarget = synchronizeFormsVersionsList

Provides the properties file name that will be used to display the Contract Transaction Versions List.

Yes
