CoreSuite NAPC : Travelers - Update Transaction Control Info

Created by Former user on Oct 25, 2019

The following questions were added to the Policy and Member nodes to hold information used as control information for the transaction.
These questions are not expected to appear in any online pages, but will be included in the Views used to generate XML for the entities listed.

EntityQ_tagXML tagDefinition
Policy30000_1361numberDriversTotal number of drivers (policyMember nodes) that are applicable on this transaction. If a driver is deleted (Action Code "D"), it does not appear in this count.
Policy30000_1362numberVehiclesTotal number of vehicles (vehicle nodes) that are applicable on this transaction. If a vehicle is deleted (Action Code "D"), it does not appear in this count.
Policy30000_1363totalWrittenPremiumQuoteAt Rate, CARS will return, the total written premium and it will be stored in a conceptual policy question. This node may or may not have a value for Rate calls. At Issue, this node will have the latest value received from Rate.
Member30011_260numberACIThe total number of Accidents/Convictions/Incidents (incident nodes) that are applicable on this transaction for this member. If an incident is deleted (Action Code "D"), it does not appear in this count.

Description

DescriptionThis method updates the new questions described above according to the following requirements. 
  • Every time the method is run, all of the questions will be reset to the value that corresponds to the current state of the transaction.
  • The source of the values for each question is:
    • numberDrivers (30000_1361) - Count the total number of drivers (policyMember nodes) of any type that are applicable on the current transaction. If a driver is deleted (Action Code "D"), it is not included in the count.
    • numberVehicles (30000_1362) - Count the total number of vehicles (vehicle nodes) of any type that are applicable on the current transaction. If a vehicle is deleted (Action Code "D"), it is not included in the count.
    • totalWrittenPremiumQuote (30000_1363) copy the value from Total Written Premium (30000_561).
    • numberACI (30011_260) - Initialize this question on each non-deleted policyMember node (of any type) by counting the total number of non-deleted Accidents/Convictions/Incidents (incident nodes) that refer to the specific policyMember via the Secondary Parent question Operator (30062-152).
  • Deleted Member entities will retain the numberACI value that was last calculated prior to the occurrence being deleted. The value will not be removed for deleted Members.
  • The results of the method will be returned to the Action using specific return codes.
