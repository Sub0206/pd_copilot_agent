CoreSuite NAPC : Update Reporting Table with XML String - No Longer Supported

Created by Former user on Oct 25, 2019

Description

DescriptionThis method will create an XML stream from the specified interface and save it in the reporting table for the associated policy.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesNone

 

XML Usage

This method requires Generated XML to be stored in the reporting table. The Step should be configured with XML-Use set to Generate from DB or Re-use from Prior Step. An Interface must also be specified to be used to generate the XML.
