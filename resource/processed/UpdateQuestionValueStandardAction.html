CoreSuite NAPC : UpdateQuestionValueStandardAction

Created by Former user, last modified on Dec 05, 2019

Update Question Value (Standard Action Only)

DescriptionThis method will update existing contract answers. If a Contract Answer does not exist already, then no update will occur. A new contract answer with the value will NOT be created. If the entity referred to is not policy, then every occurrence of the entity type that exists will be updated.

A repeating group of attributes will be accepted for this method. Each attribute will specify a question and the value that should be updated.

Enforce Stage on the answer is copied from the existing answer and used with the updated value.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.

Note that the following Questions should not be used:

- Guest Questions are not supported with this method. Only the host question should be updated via this method.
- Customer Link Questions.
- Secondary Parent Questions.
- Multi-Value Questions
- Policy Facts
- Derived Question (Answer Source = Derived)
Suggested DependenciesNone
NotesIf this method is used to update a Linked Question or a Question that uses Answer Options, it is suggested it be followed by a Rule Reapplication or Upload Step that processes those same Questions within the context of a View. This is suggested because the method sets the Contract Answer value and attempts to set the appropriate literal (note that if the literal is changed via exception or versioning, the detail view is not processed which means it is possible the incorrect literal is set). Rule Reapplication or Upload will execute the view and set the correct literal for the question.

If the Step Attribute Value is "CurrentDate()", or "CurrentDateTime()" the current date or timestamp is used to create the answer value.

Also, policy level questions can be used as a source of the answer to be set. If a value of Q_30000_## is specified, then the value of the specified question (and its related information such as literal) will be copied.

If the Value is "CurrentDate()", or "CurrentDateTime()" the current date or timestamp is used to create the answer value.

Otherwise, the value specified is used as the value to set in the answer. if the Question has Answer Options, the value specified should be the Code value for the correct Answer Option.
