CoreSuite NAPC : UpdateRelatedAllocation

Created by Former user on Oct 25, 2019

Create/Upload Related Allocation

DescriptionThis method will update the related Entity (identified using the targetMCID, targetCTID, targetVersion, and targetParentCID attributes) using the sourcePaidAmtQtag value.  A validation will be done by the method to confirm that the source amount (sourcePaidAmtQTag) value is less than or equal to the target amount value (targetBalanceAmtQTag).  Upon successful valdation, the targetPaidAmtQtag is updated using the sourcePaidAmtQtag and a child Allocation record will be created using targetChildMCID, targetChildCTID, targetChildVersion, and targetChildPaidAmtQtag using the sourcePaidAmtQtag.   
Supported Action TypeView Action 
ConstraintsMust be executed within an Allocation Template.
Suggested DependenciesIf Allocation type is not equal to type Receivable.
NotesNone

 

XML Usage

Generate from Detail View

Attributes

 There will be seven Attributes required for this method.  This first four Attributes will always be MC-ID, CT-ID, Version, and Parent C-ID.  The next two Attributes will be Views that hold both the Target and Source information, the Code will be INTERFACE and the Value will be the I-Tag name.
