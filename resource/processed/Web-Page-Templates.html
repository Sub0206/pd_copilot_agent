A Detail Presentation defines what questions should be asked for a particular contract occurrence.

List

Policy(Generic)

Billing

A List Presentation is used to display multiple occurrences of a particular entity. One view is specified. A list can be used to launch other lists or detail presentations.

List + Detail

Policy(Generic)

Billing

The List + Detail Template uses the Standard List Properties and Standard Detail Properties. Several additional properties need to be included in the Detail Properties file when used with a List + Detail Template.

Policy(Generic)The List + Multiple Detail Template uses the Standard List Properties and Standard Detail Properties. Several additional properties need to be included in the Detail Properties file when used with a List + Multiple Detail Template.

List + Detail + Updateable List

Policy(Generic)This List + Detail + Updateable List Template allows a user to click an Add/Edit button from a List and will allow them to capture the detail of the occurrence (of the list) as well as children occurrences via an updateable list.  Note that via configuration, the Updatable List may be optinal.

Grandparent Detail + Updateable List + Updateable ListBilling(Specific)This template allows for the capture of a Parent Detail along with two updateable lists which may sit on the same entity or on sibling children entities of the parent or grandparent

Updateable List

Policy(Generic)

Billing

An updateable list presentation requires 2 different views to be set up. The first view is a detail view that sits upon a parent entity. The second view is an updateable list view that sits upon the child entity. Children occurrences are added in one shot (if parent entity does not exist, then that is added first, then all the children at one time).

Detail + Updateable List

Policy(Generic)

Billing

Detail of a parent occurrence that is paired with an Updateable List that is the direct child of the parent occurrence.
Detail + Updateable List + Updateable List

Policy(Generic)

Billing

The parent item is displayed in a Detail at the top of the page while information for a single child entity with two Updateable List Views (using a View Item Filter to separate occurrences) OR 2 children (siblings) entities of the same parent each having their own Updateable List.

Search Detail + Dual Lists

Policy(Generic)

Billing

This Template supports use of an Alternate Menu container as well as a configured Detail View to manage the detailed search criteria provided by the user. Two configured List Views are used to display the returned list of results from the search.  An optional third panel provides a single string entry and can be assembled by the query used to complete the data for the second list.
