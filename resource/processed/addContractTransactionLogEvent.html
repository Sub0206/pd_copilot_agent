Add Contract Transaction Log Event

DescriptionThis method will allow for the creation of a new row in the Contract Transaction Log. The step will accept 1 required attribute and a set of optional attributes.
Supported Action TypeStandard
ConstraintsNone
Suggested DependenciesNone
Notes
  • The step will accept one required attribute and a set of optional attributes. Note that if extra data is carried on the table through installation specific columns, this data is a point in time representation of that data. If the value changes on the policy, this table will NOT be updated automatically.
  • On the Product Step Attribute screen, the Append Last Occurrence Error Text? (20010_9) question will allow the user to append error information that is captured by a step outcome to be included in the Contract Transaction Log Event Info column. It's values are Yes(Y) and No(N) and it determines if the error text from the last Outcome should be appended to the EVENT_INFO Value when populating the Contract Transaction Log occurrence.
