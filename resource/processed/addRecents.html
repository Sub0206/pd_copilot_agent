Add To Recents

DescriptionThis Method will use the specified attributes to add to the User_Frequent_Occ a new "recent" row.
Supported Action TypeStandard
ConstraintsMust be executed from within a Contract Transaction context. 
Suggested DependenciesNone
Notes

This method will create a new row if the Type, Category, MPID, MC, CT, Version and C-ID combination does not exist.  If the combination already exists, then the existing row will have its Seq_No column reset using a new Oracle Sequence number giving the next highest number for the table. 

This method will automatically set the following columns in the table:

Set Type = R

Set MCID to the current MCID in context.

Set CTID to the current CTID in context.

Set Version to the current Version in context.

Set CID to a single Occurrence ID made available to the Action.  Note that if multiple IDs are passed to the Action an error return code will be returned.  If No ID is passed, then set the value to 1. 

Seq_No will be set via an Oracle Sequence giving the next highest number for the table.

Category is set via the Attribute below.
