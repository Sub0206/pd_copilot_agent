Adjust Pending Customer Records Effective Date

Description

Uses the current transaction in context to identify any associated pending Customer Records in the installation. 

For those items identified, update the Effective Date of the record to match the Transaction Effective Date on the current transaction. 

Supported Action TypeStandard
ConstraintsNone
Suggested DependenciesNone
Notes

Can be used to sync up the pending Customer records with the current transaction if there is any doubt as to the alignment of the data.
