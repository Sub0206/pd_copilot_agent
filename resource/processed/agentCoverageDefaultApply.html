Agent Coverage Default - Apply

DescriptionThis method applies a stored Agent coverage template to the MC, CT, Version in context.
Supported Action TypeStandard
ConstraintsThere must be an MC, CT, and Version set in context for this method to work.
Each product group must have a customized XSLT that must be created to both store and apply the personalized templates which uses the specific B-tags for the coverages.
The XSLT typically is written to remove all coverages and then apply the coverages stored using the Agent Coverage Default - Store internal method.
Suggested DependenciesThere must exist at least one coverage attachment level policy occurrence on the policy.
NotesQuestions 30000_41 (Agent Code), 30000_1 (Product Group), 30000_4 (Country), and 30000_5 (State) will be used from the policy transaction in context to retrieve the Coverage information.
This method pulls the information from the stored coverage XML (stored by Agent Coverage Default - Store internal method) and uses it in combination with the current policy XML from the MC, CT and Version in context to create an upload XML which should be uploaded in an Action Step following this Action Step.

XML Usage

Generate from DB. An XSLT (see attributes) is used to take the policy XML from the current MC, CT, and Version in context and the previously stored XML (saved by the Agent Coverage Default - Store internal method) and creates an update XML.

Attributes

The only attribute specified is an XSLT which takes the policy xml generated and the XML pulled from storage and creates an Upload XML for a subsequent Upload Action Step.
