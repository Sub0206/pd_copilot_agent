Agent Coverage Default - Store

DescriptionThis method creates an Agent-specific coverage template for the current Product Group, Country and State based upon the policy transaction in context.
Supported Action TypeStandard
ConstraintsThere must be an MC, CT, and Version set in context for this method to work.
Each product group must have a customized XSLT that must be created to both store and apply the personalized templates which uses the specific B-tags for the coverages.
Also, there must be occurrences with coverages attached for this method. Minimum checks for coverage attachment entities should be configured.
Suggested DependenciesThere must exist at least one Coverage occurrence on the policy in context.
NotesQuestions 30000_41 (Agent Code), 30000_1 (Product Group), 30000_4 (Country), and 30000_5 (State) will be used from the policy transaction in context to store the Coverage information. This information is typically paired with the Agent Coverage Template - Apply internal method which uses the stored information to update new policies.

XML Usage

Accept XML for Update. Typically, the prior step generates the policy XML, transforms the policy XML into the Coverage XML needed for the Agent Coverage Template - Apply method.
