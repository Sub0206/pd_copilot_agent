CoreSuite NAPC : allocatePayment

Created by Jagadish Rotti, last modified on May 15, 2024

Run Payment Allocation

Description

This method will process an algorithm that will use the targets of a payment that has a balance and create payment allocations for receivables which will reduce the amount owed.

Supported Action Type

Standard

Constraints

Must be executed from within the Sapiens Billing System

Suggested Dependencies

None

Notes

None


XML Usage

Accept and Update
