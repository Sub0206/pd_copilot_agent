CoreSuite NAPC : allocateReceivable

Created by Former user on Oct 25, 2019

Allocate Receivables

DescriptionThis method will update the related Receivable Entity (identified using the  targetMCID, targetCTID, targetVersion, and targetCID attributes)  using the sourceAmtQtag value.  A validation will be done by the method to confirm that the source amount (sourceAmtQTag) value is less than or equal to the target amount value (receivableBalanceAmtQTag).  Once the validation is successful the sourceAmtQtag will be used to update the receivablePaidAmtQTag.
Supported Action TypeView Action
ConstraintsMust be executed within an Allocation Template
Suggested DependenciesNone
NotesNone

 

XML Usage

Generate from Detail View

Attributes

There will be twelve Attributes required for this method.  This first four Attributes will be always be MC-ID, CT-ID, Version, and C-ID which will identify the target receivable occurrence.  The next six Attributes will be Qtags that will identify the receivable amounts of what has already been paid and the balance of what’s left, the source Remittance Allocation amount that will be used to update the Receivable amount paid, the Remittance Applied amount and Remittance remaining amount and the Remittance Allocation Status.  The last two Attributes will be the Interface that will have the Views with the Attribute Qtags, Receivable XML View to update the Receivable amounts and the Parent View Tag of the Allocation Entity.
