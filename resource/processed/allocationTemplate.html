CoreSuite NAPC : allocationTemplate

Created by Susan Wilson, last modified on 20 Nov, 2019

 

The Allocation Template consists of five Adaptive Units. 
  • A Detail + Updateable List will be used to capture information about the Remittance (Detail) and the Allocations of the Remittance to related Receivables (Updateable List). 
  • A Search Detail and Search Results List will be used to find more receivables that are to be allocated for the Remittance in context. 
  • A second optional Updateable List to update the Remittance Instructions used for allocations..

 

 

Web Page Property files are used to control the settings required for the various Templates configured as Web Pages in PolicyWriter.
