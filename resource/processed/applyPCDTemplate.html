Personalized Coverage Template - Apply

DescriptionThis method applies a stored personalized coverage template to a quote using an upload process on the current New Business like quote/application.
Supported Action TypeStandard
ConstraintsEach product group must have a customized XSLT that must be created to both store and apply the personalized templates which uses the specific B-tags for the coverages.
Suggested DependenciesNone
NotesThis method is to be used as a single Step in a more complex Policy Action.

Attributes

None

Return Codes

Return CodeDescription
1Success
2No PCD template exists for the key
-1Unspecified failure
