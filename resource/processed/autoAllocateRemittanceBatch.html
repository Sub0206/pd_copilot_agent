Auto Allocate Remittance Batch

DescriptionThis method will process algorithms that will Allocate Receivables to Remittances.  The algorithm will perform the allocations based on the set of Remittance IDs passed to it but if there are no Remittance IDs passed then the IDs are searched for in the Remittance Batch in context and all that match the necessary criteria are  processed.  Determining if an Instruction can be processed is done by two checks.  First the Used indicator needs to set to No and that is known by the field BM_REMITTANCE_INSTRUCTION.USED_IND being set to N. The second check is to see if a policy is found under an Account in the Billing System, this is known by the field BM_REMITTANCE_INSTRUCTION.POLICY_FOUND_IND being set to Y.   The logic to process the Remittance Instructions is described below.
