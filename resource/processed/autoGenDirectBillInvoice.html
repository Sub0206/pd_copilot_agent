Generate Direct Bill Invoice

Description  

This method will process an algorithm that will generate invoices for direct bill accounts 

The code will mark the occurrence of the newly created Invoice ID so that later steps in a configured Action could use the filtered XML for the marked occurrence. 

Supported Action Type 

Standard 

Constraints  

Must be executed from within the Adaptik Billing System 

Suggested Dependencies  

None  

Notes  

None 

XML Usage 

Accept XML for Update 

Attributes 

Upon selection of this Internal Method, the following step attribute occurrences will be automatically created. 

A new Step Attribute Question with valid types will be created to support this method
