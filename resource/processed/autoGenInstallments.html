CoreSuite NAPC : autoGenInstallments

Created by Former user, last modified by Jagadish Rotti on Nov 09, 2023

 Auto Generate Installments

Description

This method will process an algorithm that will generate receivables from Policy Transactions governed by Pay Plan Installment Lines of the Policy.  The algorithm will perform the generation based on the set of Policy Transaction IDs passed to it but if there are no Policy Transaction IDs passed then the IDs are searched for the Account in context and all that match the necessary criteria are processed.

Supported Action TypeStandard
Constraints

Must be executed from within the Adaptik Billing System

Suggested DependenciesNone
NotesNone
