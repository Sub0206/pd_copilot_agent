Identifies the Invoicing Group that should have the Installment Fee added to it.  The value from this Step Attribute will be the code value of the Group (the value stored in the table column BM_RECEIVABLE.INVOICE_GROUP).

If this Step Attribute is missing and the method has identified that the policy receivables have grouping and an installment should be created (SUPPRESS_INST_FEE = ‘F’ or ‘N’), the invoice is not generated and a return code of ‘7’ is returned.

If this step attribute is found but there is no grouping identified, the invoice is created as normal and the installment fee (if set to create) is added as discussed in this spec.

560

RECALC_BILL_IMMED

I/M/N

The default is ‘N’

Text

This is an optional attribute and only applicable if RECALC_DUEDATE_IND is set to ‘Y’.  If this attribute is missing or not applicable, the default behavior is set to ‘N’.

If the Attribute is applicable and is set to ‘I’, the updated Receivable Due Date is based on the current date for it’s billing, this could create an out of cycle bill. 

Or if the Attribute is applicable and set to ‘M’, the receivable(s) will use the next billable month, which could also create an out of cycle bill.

Otherwise, the default behavior for this Attribute is “N” to use the Next Billable Installment to recalculate to, the receivable due date and it’s other billing dates are updated to the next billable installment.
