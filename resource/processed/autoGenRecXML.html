CoreSuite NAPC : autoGenRecXML

Created by Jagadish Rotti, last modified on Nov 26, 2020

Receivable Generation Algorithm in XML

Description

This method will use XML as input to process an algorithm that will generate receivables from Policy Transactions governed by Pay Plan attributes.  The results will generate Adaptik XML.

Supported Action Type

Standard

Constraints

Must be executed from within the Adaptik Billing System

Suggested Dependencies

None

Notes

None


XML Usage

Accept XML for Update

Identifies the minimum number of days needed to generate a receivable/invoice as it pertains to the upcoming Receivable Due Date. This attribute is used for subsequent transactions.
