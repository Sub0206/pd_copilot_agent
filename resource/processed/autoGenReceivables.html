Auto Generate Receivables

DescriptionThis method will process an algorithm that will generate receivables from Policy Transactions governed by Pay Plan attributes on the Policy.  The algorithm will perform the generation based on the set of Policy Transaction IDs passed to it but if there are no Policy Transaction IDs passed then the IDs are searched for the Account in context and all that match the necessary criteria are  processed.. The logic to process the Policy Transactions is described below.   
Supported Action TypeStandard
