Backout Transaction

DescriptionMarks the transaction in context as backed out by setting the removal code value to R and initializing the removal timestamp to the current date and time. If there is no transaction in context, the Backout will use the input XML Transaction Type and Subtype fields to identify the type of transaction to be backed out on the policy in context, will search for the latest active issued transaction of that type, and will perform the backout of the identified transaction.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy context and requires XML if there is no specific transaction in context.
Suggested Dependenciesremoval_code <> P (Pending Removal) or R (Removed)
Notes 

 

XML Usage

Optionally accepts XML for update to be used to extract the target Transaction Type and Subtype when there is no specific transaction in context.

Attributes

None
