CoreSuite NAPC : callActionMacro

Created by Former user, last modified on Dec 05, 2019

Call Action Macro

DescriptionThis method allows the current Action to invoke an Action Macro as part of its execution.
Supported Action TypeStandard & Detail View
ConstraintsThe Action Macro code Attribute must refer to an Action which is defined to be a Macro.
Suggested DependenciesNone
NotesNone

 

XML Usage

None

Attributes

This method requires the code of the Action Macro to be called configured as an Attribute.

Return Codes

Return Code
Description
AllAll return codes are determined by the Macro called. It will return whatever return codes are configured in the Macro Outcomes
-1Unspecified Failure

 

Implementation Example

Action

Issue

Action Type

Standard Action

Dependency

None

Action Step

Call SYNC_ISSUE macro

Outcomes

None, the subsequent step uses an Evaluate Outcomes only and checks the return information from the Macro.

Attributes

One Attribute is required that contains the code of the Action Macro to call, in this example SYNCUP_ISSUE.
