Created by Former user on Oct 25, 2019

Cancel Disbursement Request

DescriptionThis method will update the related Entity (identified using the targetMCID, targetVersion, and targetCID attributes) using the sourcePaidAmtQtag value.  The tarPendingAmtQTag and  srcParentAmtQTAG are decreased using the sourcePaidAmtQtag and the createDateQTAG is cleared.
Supported Action TypeView Action
ConstraintsMust be executed within an Allocation Template
Suggested DependenciesIf Allocation type is not equal to type Receivable.
NotesNone

 

XML Usage

Generate from Detail View

Attributes

There will be eleven Attributes required for this method.  This first four Attributes will always be MC-ID, CT-ID, Version, and C-ID.  The next five Attributes will be pointing to the QTAGS used in updating the amounts on the Parent Source and Target entities. The last two Attributes will be the Interface that will have the Views with the Attribute Qtags, Receivable XML View to update the Receivable amounts and the Parent View Tag of the Allocation Entity.
