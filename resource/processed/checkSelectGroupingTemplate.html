CoreSuite NAPC : checkSelectGroupingTemplate

Created by Susan Wilson, last modified on 05 Dec, 2019

 

Check Select Grouping (Parent)

  • Can only allow for the selection of Product Occurrences which store information on the particular policy.
  • Can only allow a single detail to capture the policy information OR capture just the selection of the occurrence (without detail information).
  • The Tabs along the top can be configured to categorize the different Product Occurrences. A single Tab (which is then hidden) may also be configured.
The Check Select Grouping (Parent) can consist of any or all of the following:
  • Paren Detail
  • Parent Occurrence Selector
  • Search Link (with corresponding Search Overlay)
  • Check Select Grouping (i.e.-Tabs)
