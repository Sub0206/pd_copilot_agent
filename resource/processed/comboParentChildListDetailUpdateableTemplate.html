CoreSuite NAPC : comboParentChildListDetailUpdateableTemplate

Created by Susan Wilson, last modified on 20 Nov, 2019

Combo Parent/Child List + Detail/Updateable List Template

This template allows a user to configure two List Views, one for the Parent and another for the Child entity. These two lists will be combined into a single List Unit and provide rows that are the combination of a parent and a single child and repeat this for each child occurrence. 

The Combo Parent/Child List + Detail/Updateable List uses the standard List Properties, the standard Details Properties, and the standard Updateable List Properties

autoAddMode

Optional

autoAddMode=Y

Automatically opens the detail if the list does not retrieve any occurrences after View Item Filtering. Overrides app.properties.

Note that the showDetailDirectly property does not need to be set as this template will automatically load the detail without sending the list to the client first. Also, if the user uses the Filter Bar, and no occurrences are shown then we will NOT create a new empty detail for the user.
 
Note that if the grandparent id is passed, then the detail loaded will be the parent detail (if there are not any occurrences), otherwise the parent list will be loaded to allow the user to choose the parent. If the parent id is passed, then the normal detail will be loaded.

scrollingEnabled

Optional

scrollingEnabled=Y

When set to Y and the number of occurrences for the entity is less than beginPagingThreshold, then the list should be in scrolling mode. If set to N, then the list is always shown in paging mode.

Default=N

beginPagingThreshold

Optional

beginPagingThreshold=50

Indicates the number of occurrences for the entity before paging is enabled (greater than or equal to) when scrollingEnabled=Y. Also indicates when filtering and sorting functionality is performed on the server vs on the client. If scrollingEnabled=N, then the paging section will not be displayed unless the number of entity occurrences surpasses this threshold OR the viewable area for the list cannot display the specified number of occurrences.  Note that the maximum number this property can contain is 300. An application exception is given to the user if a higher number is specified.

Default=200, if scrollingEnabled=Y
  
Default=5 otherwise

Detail properties

The following properties need to be added/updated in the Detail List properties file :

Property Name 

Description 

Example 

listAppliesQTag 

(Optional) 

The Updateable List will be hidden and the child occurrences deleted (if they existed) upon submit of the page if the specified Question exists with a value of “N”. Note that this Question must be made server sensitive. If the Question does not exist or has any other value, the Updateable List will be applicable and shown to the user. 

listAppliesQTag= 
Q_30010_123 

listSensitivityQTag 

(Optional) 

If the value of this QTag is changed AND the Updateable List is shown based on the listAppliesQTag then the listSensitivityAction will be executed in order to prepopulate the Updateable List. 

If the Updateable List is not visible due to the listAppliesQTag being evaluated to “N” then this property should be ignored. 

NOTE: Only supported in Add mode 

listSensitivityQTag=Q_30010_321 

listSensitivityAction 

(Optional) 

The Code of the Standard Action that should be executed in order to populate the Updateable List using Intermediate List XML. 

This action will only be executed if the listAppliesQTag evaluates to a non ‘N’ value to display the list, and if the Action Code is configured, is applicable. 

If this property is not configured then there will be no attempt to run any Action. 

NOTE: Only supported in Add mode 

listSensitivityAction=populateAdd 
IntSched
