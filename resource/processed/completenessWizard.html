Completeness Wizard

DescriptionValidates whether any missing answers remain on the transaction which have an Enforce Stage that is less than the Policy Stage value specified in the Attribute or which have incomplete service calls associated with an occurrence. An Interface (specified as a Step Attribute) is used to match the missing answers, failed service calls, and invalid View Item Errors to the appropriate web pages.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesThis method is typically used when converting from a quote to an application.
