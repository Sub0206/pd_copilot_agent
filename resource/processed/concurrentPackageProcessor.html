CoreSuite NAPC : concurrentPackageProcessor

Created by Former user on Oct 25, 2019

Create Concurrent Packages

DescriptionThis method will remove, by setting the Removal Code value of Deleted (D), all existing versions, including any Custom Version as well as any existing Versions marked as Inactive Coverage Package Version (Z), of the policy transaction in context. The version in context will also be removed if the DELETEIND Attribute indicates it should be. Next, the method will use the version in context as the basis to create new versions, one for each applicable Coverage Package occurrence defined by entity 20105. On each version, the Coverage Package Code (30000-133) Question will be set to the corresponding Coverage Package Code.
Once the Versions have been created, if the REMOVEVERS Attribute is set to Y, each Coverage Package Version, except the current version, will be marked as removed using the Removal Code Inactive Coverage Package Version (Z). Any corresponding rows in the Search Cache (Alternate Query Table) will also be removed to prevent the Versions from being returned in a Search activity.
The target B-tag, Product List View, Sequence Number, and column reference will be taken from the configuration of the 30000-133 question in the Product. Note that this question is temporarily set during the package creation method and is then removed once the coverages have been applied.
Supported Action TypeStandard
ConstraintsThe Coverage Package Question (30000-133) must be configured as a linked question to the Coverage Package Product Entity and should be an exception factor on the Coverage Linked questions.
This method is only supported in a base transaction context (CT ID = 1; NB, CONV, REWRITE). If it is executed in a subsequent transaction context it will throw an exception..
Suggested DependenciesNone
NotesThis method is to be used as a single Step in a more complex Policy Action.
