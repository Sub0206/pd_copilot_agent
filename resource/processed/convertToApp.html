Convert Quote to Application

DescriptionUpdates the Quote to an Application by setting the Transaction Subtype from Quote (QT) to Application (AP). Typically only used with the New Business (NB) Transaction Type.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesTransaction Type = New Business Transaction Subtype = Quote removal_code <> P (Pending Removal) or R (Removed)
NotesNone
