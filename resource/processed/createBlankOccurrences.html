Create Blank Occurrences

DescriptionThis method is used to create a specified number of new, largely blank, occurrences of a provided view type by creating each occurrence and adding the view identified in the Attributes to it.
The occurrences will be created regardless of the number of occurrences that already exist on the policy for that V-Tag.
This method will NOT check for a maximum number of occurrences allowed to be created. It is the responsibility of the Product Designer Configurator to make sure that the maximum number of occurrences is not exceeded if a maximum exists.
Supported Action TypeStandard
ConstraintsThis method can only be used to create immediate children of the Policy (30000) entity.
Suggested DependenciesNone
NotesNone

None

Value
Type

Note that the Value should be a valid V-Tag for the Entity type that is being created.
