Create DOC

DescriptionThis method accepts XML, either generated, input or received from previous steps. A specified XSLT runs that produces the information into the required DOC representation. The resulting DOC is then available to subsequent steps for display. The expectation is that any file format supported by Microsoft Word will work.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesRequires that an XML Generation I-Tag (Interface) be specified on the Step Detail page.
May require Adaptik intervention to ensure DOC output format meets business need. Generated data is conatined in PWDocument for the subsequent Steps.

 

XML Usage

Requires generated or reused XML be provided to the method.
