CoreSuite NAPC : createInstallmentRevision

Created by Jagadish Rotti, last modified on Jul 25, 2022

Create Installment Revision

Description

This method will process an algorithm that will use the View data (that’s identified as a step attribute) and first validate that the “revised” installments meet the criteria to create new receivables and if they do, the new receivables and invoices are created.  The “old” receivables and invoices will be reversed.     

Supported Action Type

Standard Action

Constraints

Must be executed from within the Adaptik Billing System
