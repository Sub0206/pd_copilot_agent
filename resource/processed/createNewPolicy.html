Create New Policy

DescriptionThis method is used to create a new policy or insurance application which will be established using the information provided in the Update XML. The Views specified in the Interface in the Action configuration will be used to receive and process the information.
This method requires a single attribute. The attribute allows the upload user to use differing sets of Views to process the data being uploaded versus the views used to process online requests.
All of the policy or insurance application information is expected to be contained in the Update XML provided. The policy transaction information (Transaction Type, Subtype, and Description, etc.) must also be included.
Supported Action TypeStandard
ConstraintsOnly New Business, Rewrite, and Conversion transaction types may be specified when creating a new policy.
Suggested DependenciesNone
NotesNone

XML Usage

This method requires Update XML to provide information to the new policy. XML- Use should be Accept XML for Update.

Attributes

The Create New Policy internal method also requires the use of one Attribute. The single Attribute must exist even if it contains no Value. The Attribute specifies any additional Views which should be marked as having been visited (similar to marking the pages as having been visited) as a result of the Upload. If no additional Views need to be marked the Attribute must still be included with an empty value.
