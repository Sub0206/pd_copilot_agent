CoreSuite NAPC : createPayables

Created by Jagadish Rotti, last modified on Jul 26, 2022

 Create Payable

Description

This method uses the staging XML from a issued policy transaction to create payable occurrences if payable instructions are included in the XML.

Supported Action Type

Standard Action

Constraints

Must be executed from within the Adaptik Billing System as part of the Post Action for new policy transactions

Suggested Dependencies

None

Notes

None


XML Usage = Reuse from Prior Step (Post Policy Transaction XML (during Post Action)
