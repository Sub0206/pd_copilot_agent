CoreSuite NAPC : createVersion

Created by Former user, last modified on Dec 05, 2019

Version Transaction

DescriptionThis method creates a new version of the current policy transaction in context by copying it (including any changes already on the transaction), sets the policy Stage and Freeze Stage values to 0, and sets that new version into context.

This method also specifically updates the Description Question by concatenating an annotation of "- Ver #". The Process Date, Referral Status Code, Rating Date Time Stamp, Underwriting Date Time Stamp, Version Number, Transaction Premium and OOS Code Questions are also updated as a part of this method.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesTransaction Subtype = Quote or Application, or Transaction Type = Policy Change or Renew
removal_code <> P (Pending Removal) or R (Removed)
