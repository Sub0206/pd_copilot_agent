Customer Clearance

Descriptiona. This method will first call a service (for which we will create a stub) to retrieve all the valid Agent Codes using the input Agent Code and input date. Any agent code attached to a policy that is not in this set will be called "other agents" below.
b. Using the input Product Group (Q_30000_1), find the Business Segment for which the Product Group belongs to (using the input date (DATE Step Attribute) and querying the 10201 Reference table). Using that Business Segment (10201_7), retrieve the list of Product Groups that belong to that Business Segment. Retrieve the 10983-6 and 10983-7 attributes from the Business segment to be used below (using Product Transaction Effective Date as the reference date).
c. Using the input Customer_id, find all quotes and policies. Remove any quote or policy that does NOT belong to the Business Segment identified in step b. If the policy (Q_30000_1) is NOT tied to a Product Group returned in step b, then it will be removed from further processing.
d. If any issued policies are found, determine if any of them are still in force by joining to policy log to get the cancel effective date or expiration date (information to be used below when setting a return code).
e. For unissued new business transactions, use the process date (Q_30000_35 from alternate query).
f. Determine the return code below by using the information from the steps above. If more than one output code applies, only the highest numbered code will be returned.
Supported Action TypeStandard
ConstraintsThere must be a Customer ID, Product Group, and Agent code.
