The Customer-Policy Quote Version Selection Template will use one property file in support of the template: 

 

Property

Value

Form Element / Behavior

Applicability

Presentation Type

CustomerPolicyVersions

Identifies the presentation type.

Required

policyDetailView

Valid V-tag on 30000 within the Product Group

Identifies the Detail View that will be used to capture the search criteria and the search button which references the specific SearchID for the installation for the Policy List.  Hidden on the page.

Required

versionDetailView

Valid V-tag on 30000 within the Product Group

Identifies the Detail View that will be used to capture the search criteria and the search button which references the specific SearchID for the installation for the Version List.  Hidden on the page.

Required

policyListView

Valid V-tag on 30000 within the Product Group

Identifies the List View that will be used to assemble the Policy List Results.

Required

versionListView

Valid V-tag on 30000 within the Product Group

Identifies the List View that will be used to assemble the Version List results (for each policy/quote).

Required

interfaceTag

Valid Interface Tag

Identifies the InterfaceTag that will be used to generate XML for each MC, CT, Version selected.  Note that this Interface must exist in all Product Groups.

Required

XMLTag

alternate_reference_code (Default), standard_reference_code, action_tag

Indicates the tag set that should be used to generate the xml.  alternate_reference_code maps to the “XML Tag” and standard_reference_code maps to Alternate XML Tag 1.  action_tag maps to Alternate XML Tag 2

Optional

needQtags

Y, N (default)

Indicates if the Q-tags should be included in the XML generation.

Optional

needIds

Y, N (default)

Indicates if the occurrence and answer id’s should be included in the XML generated

Optional

includeTransInfo

Y, N (default)

Indicates if the transaction information (Action tags) should be included. Occurrneces that have been deleted will be suppressed if set to N.

Optional

suppressEmptyTags

Y, N (default)

Target

action, XSL

Indicates that the XML should be sent to an Action for further processing or sent to an XSL that will produce an HTML to display in the main body.

Required

actionCode

Valid Action Code for the MC, CT, Version in context.

Provides the Action Code that will be used to accept the XML produced by the template.

Required when Target=action

XSLReference

XSL file name. 

File that will be used to transform the XML generated into an HTML that will be displayed in the main body.

Required when Target=XSL
