CoreSuite NAPC : deleteChildOccurrences

Created by Former user, last modified on Dec 05, 2019

Delete Entity Child Occurrences

DescriptionDeletes all occurrences of the specified entity type (primary) or secondary parent children nodes of the current occurrence in context. Does not delete the current occurrence in context.
Supported Action TypeDetail View
ConstraintsTested only for use with vehicle Replace functionality.
Suggested DependenciesNone
NotesNone

 

XML Usage

None

Attributes

PRI_BTAG_LISTContains a comma separated list of B-Tags for entities that have the page's entity type as a primary parent. Any occurrences of these entity types that are primary children of the current occurrence will be deleted.
SEC_QTAG_LISTContains a comma separated list of Secondary Parent Question Q-Tags in entities that have the page's entity type as a secondary parent. Any occurrences of these entity types where the specified question contains the identifier for the occurrence being replaced (in context) as secondary children will be deleted.

Return Codes

Return Code
Description
1Successful delete
2No occurrences Found
3Failure
4MC not in context
-1Unspecified Failure
