Delete System Messages

DescriptionThis method deletes any Rule Reapplication or Upload System Messages present on the policy or only those identified by the type specified in the Attribute. These items are not managed as ordinary contract occurrences and cannot be deleted using other internal methods.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesNone

 

XML Usage

None

Attributes

This method requires a single Attribute to specify the type or types of messages to be deleted. If more than one type is specified, the values must be comma separated within the Value property of the Attribute. Valid values include:

  • A all messages
  • C Completeness check messages
  • U Upload messages
  • R Rule Reapplication messages

Return Codes

Return Code
Description
1Success
3Failure - No MC, CT, Version in context
-1Unspecified Failure
