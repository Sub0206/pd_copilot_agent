CoreSuite NAPC : detail2UpdateableListTemplate

Created by Susan Wilson on 25 Oct, 2019
The Detail + Updateable List + Updateable List consists of one Detail Unit and two Updateable List Units.
  • The parent item is displayed in a Detail at the top of the page while information for a single child entity with two Updateable List Views (using a View Item Filter to separate occurrences) OR 2 children (siblings) entities of the same parent each having their own Updateable List.
The Detail + Updateable List + Updateable List Template uses the Standard Detail Properties and two Standard Updateable List Properties. Additionally, the following properties need to be included in the Detail Properties file: 
Property ParameterUsageExample ValuesDescriptionComments
listAppliesQTagRequiredValid Q-Tag (Q_3####_#)
Example: 
listAppliesQTag=Q_30000_999		Updateable List OR List + Detail will be hidden and the child occurrences deleted (if they existed) upon submit of the page if the specified Question exists with a value of "N".
Note that this Question must be made server sensitive. If the Question does not exist or has any other value, the Updateable List will be applicable and shown to the user.		Works with FIRST Updateable List ONLY
summaryAppliesQTagOptionalValid Q-Tag (Q_3####_#)
Example: 
summaryAppliesQTag=Q_30014_31

Indicates that a column in the schedule should be used to update a Question in the parent detail with a summation of the values in the rows.
If the specified Question is populated with a "Y", then the summarySourceQTag and summaryTargetQTag are REQUIRED. If the property is missing OR the value is NOT Y,
then no summation will be completed.

Works with FIRST Updateable List ONLY
summarySourceQTagOptionalValid Q-Tag (Q_3####_#)
Example: 
summarySourceQTag=Q_30095_2		Identifies the Question in the schedule that should be used for the summation that updates the summaryTargetQTag target in the parent detail.
This question MUST be included in the parent detail view.		Works with FIRST Updateable List ONLY
summaryTargetQTagOptionalValid Q-Tag (Q_3####_#)
Example: 
summaryTargetQTag=Q_30014_2		Identifies the Question in the parent detail that should be updated with the summation of values from the schedule (summarySourceQTag).
This question MUST be included in the schedule (updateable List or child Detail Views).		Works with FIRST Updateable List ONLY
deleteParentOptionalY, N (default)
deleteParent=Y		Can only be used if the template is a Detail + Updateable List. Indicates that the parent occurrence should be deleted when the last row of the updateable list is deleted
(happens upon submit of the page).		NOT Supported with this Template

enableSorting=Y		Indicates if the Updateable List will allow the user to sort the rows on the client.  When the property is not present or set to Y, then sorting will be disabled on the client 
scrollingEnabledOptional

Y (Default), N

Example:
scrollingEnabled=Y 

When set to Y and the number of occurrences for the entity is less than beginPagingThreshold, then the updateable list should be in scrolling mode.  If set to N, then the list is always shown in paging mode.  Also indicates when filtering and sorting functionality is performed on the server (paging) vs. on the client (scrolling). 

Default = Y
beginPagingThresholdOptional

Whole Number

Example:
beginPagingThreshold=50

Indicates the number of occurrences for the entity before paging is enabled (greater than or equal to) when scrollingEnabled=Y.  Note that the maximum number this property can contain is 100.  An application exception is given to the user if a higher number is specified.

Default = 25 if scrollingEnabled=Y
pageSizeOptional

Whole Number

Example:
pageSize=15 

Indicates the number of occurrences that should be shown inside of each "page".  If the number of rows is less than the page size and scrollingEnabled=N, then the paging controls will be suppressed from view as there are no additional "pages" of occurrences to navigate to.

Default = 10
enableRowNumberingOptional

Y, N (Default)

Example:
enableRowNumbering=Y 

Indicates if a row number should be displayed on each row of the updateable list.  

Default=N
