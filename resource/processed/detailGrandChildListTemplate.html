CoreSuite NAPC : detailGrandChildListTemplate

Created by Susan Wilson, last modified on 20 Nov, 2019

 

Web Page Property files are used to control the settings required for the various Templates configured as Web Pages in PolicyWriter.

 

Alternate Menu Container

An Alternate Menu Container will be used to allow different configurable Web Pages to be set in context of the Detail information presented above it.  The menu links will appear as tabs that separate the Detail and List Views.

Each Web Page that is used as menu links will identify the Alt Menu Code as the Parent Web Page Code 

The Detail + AltMenu + GrandChildList Template uses the Standard Detail Properties and Standard List Properties

copyTypeOptional

include, exclude (default)

Example:

copyType = exclude

Used in conjunction with Copy function (from a list).  When this property is specified, there must be a copyQTags property specified that provides a list of Questions.

Using the highlighted row, and clicking Copy button (from a list), questions from the highlighted occurrence will be taken and used as the basis for the new occurrences created (when copyType=include).
 

If copyType=exclude, then questions listed will NOT be included in the new occurrences, and all other questions on the occurrence will be used.

buttonsOnRowIndOptional

Y, N

Example:
buttonsOnRowInd=Y 

When set to Y, the Edit, Delete and all other function types that are occurrence based will be rendered on each row and the selection paradigm should be removed.
 

When set to N (Default) an occurrence will be selectable and the Function Types will be executed in context of the occurrence selected.

Only applicable when displayType has a value of stacked

 

wrapHeaderTextOptional

Y, N (Default)

Example:

wrapHeaderText=Y		When set to Y, the text within the Header row of a list should be wrapped.  When set to N, the "..." notation will be used to denote that there is more text than can fit in the header cell and the mouse over will be provided to show the full text. 
wrapRowTextOptional

Y, N (Default)

Example:

wrapRowText=Y

When set to Y, the text within the row cells of a list should be wrapped.  When set to N, the "..." notation will be used to denote that there is more text than can fit in the header cell and the mouse over will be provided to show the full text. 

Note that this property will be ignored when any of the following properties are set with the following values: 

  • displayType=combo or stacked
  • scrollingEnabled=N
