Detail + List + Detail Template

 

The Detail+ List + Detail Template consists of three Adaptive Units, two Detail Adaptive Units and the List Adaptive Unit to allow for both viewing and updating of both the parent and children items.
The parent item is displayed in a Detail at the top of the page while the children appear in a List Adaptive Unit below it. Information on the selected child item may be updated in another Detail below the List on the same page or on a subsequent page depending on how the Template is configured. The information in this Detail for each List item can vary based upon configuration.
This Template is useful if you need to display information from the parent that relates to the child occurrences or provides context for the List.

 

Web Page Property files are used to control the settings required for the various Templates configured as Web Pages.

 

The Detail + List + Detail Template uses the Standard List Properties and two Standard Detail Properties, one for Parent Detail and one for Child Detail.

If the property is missing OR the value is NOT Y, then no summation will be completed.

Note that this property will be ignored when any of the following properties are set with the following values: 

  • displayType=combo or stacked
  • scrollingEnabled=N
