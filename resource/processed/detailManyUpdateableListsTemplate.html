CoreSuite NAPC : detailManyUpdateableListsTemplate

Created by Susan Wilson, last modified on 20 Nov, 2019
The Detail + Multiple Updateable Lists Template provides the ability to display on a single page a detail and multiple updateable lists.

Supported features:

  1. The questions for each occurrence will be controlled by standard configuration techniques.
  2. Each Updateable list will support client side sorting and filtering.
  3. Rows representing column totals will be available for each Updateable List. (Configured by designating Yes for Summarize Column? On View Item)

Unsupported features that are present in a single Detail + Updatable List template:

  1. There will be no support for the functionality known as “sum to Parent” that is designated in the Parent Detail property file.
  2. There will be no support for the functionality known as “deleteParent” that is designated in the Parent Detail property file.
  3. There will be no support for intervening Details between the Updateable Lists.
  4. There will be no support for button/action support on any of the Updateable Lists.
  5. There will be no support for paging on any of the Updateable Lists.

Unsupported features:

  1. Answer Actions will not be supported on each row of the Updateable List.
  2. Server sensitivity that supports features such as Reference or Product Link derivations will not be supported.

wrapHeaderTextOptional

Y, N (Default)

Example:

When set to Y, the text within the Header row of a list should be wrapped.  When set to N, the "..." notation will be used to

denote that there is more text than can fit in the header cell and the mouse over will be provided to show the full text.

wrapRowTextOptional

Y, N (Default)

Example:

wrapRowText=Y

When set to Y, the text within the Header row of a list should be wrapped.  When set to N, the "..." notation will be used to

denote that there is more text than can fit in the header cell and the mouse over will be provided to show the full text.

enableFilteringOptional

Y, N (Default)

Example:

enableFiltering=Y

Indicates if the filter row should be enabled or disabled. 

When property is present and set to N, the filter row will be hidden from the user.

enableSortingOptional

Y, N (Default)

Example:

enableSorting=Y

Indicates if the Updateable List will allow the user to sort the rows on the client. 

When the property is not present or set to Y, then sorting will be disabled on the client

scrollingEnabledOptional

Y (Default), N

Example:
scrollingEnabled=Y 

When set to Y and the number of occurrences for the entity is less than beginPagingThreshold, the updateable list should be in scrolling mode. 

If set to N, then the list is always shown in paging mode. 

Also indicates when filtering and sorting functionality is performed on the server (paging) vs. on the client (scrolling). 

enableRowNumberingOptional

Y, N (Default)

Example:
enableRowNumbering=Y 

Indicates if a row number should be displayed on each row of the updateable list.
