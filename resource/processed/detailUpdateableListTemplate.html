CoreSuite NAPC : detailUpdateableListTemplate

Created by Susan Wilson, last modified on 05 Dec, 2019

 

The Detail + Updateable List consists of two Units, both the simple Detail Unit and Updateable List Unit.
  • The parent item is displayed in a Detail at the top of the page while the children appear in the Updateable List Unit below it.
  • Information on a selected child may be updated directly in the Updateable List on the page.
  • This Template can be used in place of the Detail + List + Detail Template but has a restriction that the Updateable List Adaptive Unit must ask the same questions for each item in the List.
  • All of the changes made in the Updateable List are applied to the transaction in a single submission.
Web Page Property files are used to control the settings required for the various Templates configured as Web Pages.

 

The Detail + Updateable List Template uses the Standard Detail Properties and the Standard Updateable List Properties. Additionally, the following properties need to be included in the Detail Properties file: 
Property ParameterUsageExample ValuesDescriptionComments
listAppliesQTagRequiredValid Q-Tag (Q_3####_#)
Example: 
listAppliesQTag=Q_30000_999		Updateable List OR List + Detail will be hidden and the child occurrences deleted (if they existed) upon submit of the page if the specified Question exists with a value of "N". Note that this Question must be made server sensitive. If the Question does not exist or has any other value, the Updateable List will be applicable and shown to the user. 
summaryAppliesQTagOptionalValid Q-Tag (Q_3####_#)
Example: 
summaryAppliesQTag=Q_30014_31		Indicates that a column in the schedule should be used to update a Question in the parent detail with a summation of the values in the rows. If the specified Question is populated with a "Y", then the summarySourceQTag and summaryTargetQTag are REQUIRED. If the property is missing OR the value is NOT Y, then no summation will be completed. 
summarySourceQTagOptionalValid Q-Tag (Q_3####_#)
Example: 
summarySourceQTag=Q_30095_2		Identifies the Question in the schedule that should be used for the summation that updates the summaryTargetQTag target in the parent detail.
This question MUST be included in the parent detail view.		 
summaryTargetQTagOptionalValid Q-Tag (Q_3####_#)
Example: 
summaryTargetQTag=Q_30014_2		Identifies the Question in the parent detail that should be updated with the summation of values from the schedule (summarySourceQTag).
This question MUST be included in the schedule (updateable List or child Detail Views).		 
deleteParentOptionalY, N (default)
deleteParent=Y		Can only be used if the template is a Detail + Updateable List. Indicates that the parent occurrence should be deleted when the last row of the updateable list is deleted (happens upon submit of the page).

enableSorting=Y		Indicates if the Updateable List will allow the user to sort the rows on the client.  When the property is not present or set to Y, then sorting will be disabled on the client 
scrollingEnabledOptional

Y (Default), N

Example:
scrollingEnabled=Y 

When set to Y and the number of occurrences for the entity is less than beginPagingThreshold, then the updateable list should be in scrolling mode.  If set to N, then the list is always shown in paging mode.  Also indicates when filtering and sorting functionality is performed on the server (paging) vs. on the client (scrolling). 

Default = Y
beginPagingThresholdOptional

Whole Number

Example:
beginPagingThreshold=50

Indicates the number of occurrences for the entity before paging is enabled (greater than or equal to) when scrollingEnabled=Y.  Note that the maximum number this property can contain is 100.  An application exception is given to the user if a higher number is specified.

Default = 25 if scrollingEnabled=Y
pageSizeOptional

Whole Number

Example:
pageSize=15 

Indicates the number of occurrences that should be shown inside of each "page".  If the number of rows is less than the page size and scrollingEnabled=N, then the paging controls will be suppressed from view as there are no additional "pages" of occurrences to navigate to.

Default = 10
enableRowNumberingOptional

Y, N (Default)

Example:
enableRowNumbering=Y 

Indicates if a row number should be displayed on each row of the updateable list.  

Default=N
