Display Document

DescriptionExtracts a binary document and queues it for display on the client when the Policy Action completes. The document will be presented in a separate browser window upon completion of the Policy Action (not within the main body of the window that started the policy action). Note that if the last Policy Action Outcome processed indicates that the Action is a "Failure" (Product Step Outcome. Does this Outcome Indicate Failure = Y), then display of any document will be aborted.
Note that if this method were embedded in an Action Macro, then the document will be returned to the caller as long as the last processed Policy Action Outcome does not indicate "Failure" (as noted above).
Note that Account Manager will take the content of the document and stream this content based upon the MIME type entered in the attribute. If the document does not match the MIME type specified, the document may not load. No additional virus scanning of the document will be performed by Account Manager.
Supported Action TypeStandard
ConstraintsNone

Notes


XML Usage

Step should be configured with XML-Use set to Accept XML for Update.

Attributes

Three attributes are applicable for this method.  The first indicates the type of Document that has been returned from the Web Service.  The Value question should be answered with the MIME Type.  In the table below, the MIME types that have been tested with Account Manager are listed.  Other MIME types may be used, but have not been validated. 

The second Attribute indicates the TARGET.  With the 7.6 release, the only valid target will be newWindow.  Future releases will include the ability to specify an overlay, main body, or a specific area within the framework.

The third attribute allows an override to the system generated file name, this can either be a hardcoded string a QTag.
