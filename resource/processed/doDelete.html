CoreSuite NAPC : doDelete

Created by Former user, last modified on Dec 05, 2019

Delete Transaction

DescriptionMarks the transaction in context as deleted by setting the removal code value to D and initializing the removal timestamp to the current date and time.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested Dependenciesremoval_code <> P (Pending Removal) or R (Removed)
NotesNone

 

XML Usage

None

Attributes

None

Return Codes

Return Code
Description
1Successful Delete of a new business transaction.
2Successful Delete of a Policy Transaction
3Failure - No MC, CT, Version in context
4Unspecified Failure
-1Unspecified Failure
