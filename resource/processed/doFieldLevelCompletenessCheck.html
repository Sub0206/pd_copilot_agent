CoreSuite NAPC : doFieldLevelCompletenessCheck

Created by Former user, last modified on Dec 05, 2019

Completeness Check - (formerly known as Field Level Completeness Check)

DescriptionValidates whether any missing answers remain on the transaction which have an Enforce Stage that is less than the Policy Stage value specified in the Attribute or which have incomplete service calls associated with an occurrence.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesThis method is not typically used by itself as an action, but as a step in a more complex Policy Action.

 

XML Usage

None

Attributes

Stage - Enforce Stage for which to check for missing answers Interface - The interface that defines the scope of the data to be validated

Value

Return Codes

Return Code
Description
