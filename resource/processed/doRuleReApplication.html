CoreSuite NAPC : doRuleReApplication

Created by Former user, last modified on Dec 05, 2019

Perform Rule ReApplication

DescriptionThis method forces a reapplication of the defined Product and Policy Configuration rules against the specified node in the policy transaction identified by the current context. The method uses a set of Views defined in an Interface to apply the configured rules from the Views to the policy transaction.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesThis method is not typically used by itself as an action, but as a step in a more complex Policy Action.
Most often used on the Policy as a whole rather than a subordinate node in the policy tree.

 

XML Usage

None

Interface Tag - defines the scope of the information to have rules reapplied. Suppress Errors Indicator - Determines behavior when errors are discovered.

10INTERFACEDefined Interface TagStringDefines the scope of the information to have rules reapplied by the Views contained in the Interface.
20SUPRESSERRORSY/NStringWhen set to Y, the method will always return the return code for Successful Completion with no updates regardless of whether updates were made to the transaction or not. The effect of this is that the user would follow any configured navigation for success.
When set to N, the method will return the correct return code that indicates whether or not changes were made to the transaction from the list of return codes below. This supports the configuration of an Outcome navigation to the errors page when errors are to be examined by the user.
30RUNFROMRENEWALY/NStringWhen Y will cause the Rule Reapplication to run any Renewal Instructions that are configured in the Views in the Interface.
