CoreSuite NAPC : doTransform

Created by Former user, last modified on Dec 05, 2019

Run XSLT

DescriptionThis method uses the specified policy interface to generate an XML representation of the information required from the current policy transaction context, and then applies a customized XSLT that converts the information into the required XML format. The resulting XML is passed into the Target Program specified on the Step Detail page.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
Notes

Requires XML Generation I-Tag (Interface) must be specified on the Step Detail page.

This method is not compatible with the Display Document method.  If the output of the XSL is to be used to display a document, then the Create Doc method should be used to run the XSL instead.

None

Return Codes

This method assumes success and returns nothing UNLESS the XML resulting from the execution of the XSLT contains the PWResponse elements. In that case, the Return Codes from the PWResponse will be used and returned as return codes.
