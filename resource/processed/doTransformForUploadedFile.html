CoreSuite NAPC : doTransformForUploadedFile

Created by Former user, last modified on Dec 05, 2019

Run XSLT on Attached File

DescriptionThis method uses the contents of a previously stored file, and then applies a customized XSLT that converts the information into the required XML format. The resulting XML is passed into the Target Program specified on the Step Detail page.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesRequires a File to have been previously uploaded and stored as an answer to a File type question.


XML Usage

None

Attributes

QTAGFORFILE - The QTAG of the File type question containing the uploaded file.
XSLT - The file name of the XSLT file to be run.
Seq #CodeValueTypeDescription
10QTAGFORFILEQTAG value for a question of type FilestringQTAG for the attached file (i.e. Q_30000_1234)
20XSLTXSLT File NamestringIdentifies the XSLT file to be run.

Return Codes

This method assumes success and returns nothing UNLESS the XML resulting from the execution of the XSLT contains the PWResponse elements. In that case, the Return Codes from the PWResponse will be used and returned as return codes.
Return CodeDescription
-1Unspecified Failure
