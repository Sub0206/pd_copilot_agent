CoreSuite NAPC : docManagementTemplate

Created by Jagadish Rotti, last modified by Susan Wilson on 19 Nov, 2019

The Document Management Template can be used to display and allow the user to manage a List or multiple Lists (maximum of 5) of documents.  These will be configured along with an optional Detail available for each List to enable modifications of metadata and potentially moving Documents to a different location.

List Properties

This list is non-standard and does not support a full set of the properties that a standard configured list can support. There is also an additional property to specify the Action Code that retrieves the list data and another to specify the reference code of the link column and the text used to display the link. The supported properties are listed below:

Property Name

Usage

Description

Example

presentationType

Required

A specific presentationType for this list, it should always be set to documentManagementList

presentationType=document
ManagementList

ViewName

Required

Specifies the name of V-Tag for the List View that will be used to supply the presentation information for the presentation type

ViewName=docLT1

retrievalActionCode

Required

Specifies the Action Code that will be executed to provide the Intermediate List style View XML that will be used to populate the list.

retrievalActionCode=
getDocuments

emptyListMessage

Required

Provides the empty list message that is displayed to the user

emptyListMessage=There are no documents of this type to display.

enableFiltering

Optional

Indicates if the filter row should be enabled or disabled. When property is present and set to N, the filter row will be hidden from the user

enableFiltering=N

Defaults to Y if not provided

wrapHeaderText

Optional

When set to Y, the text within the Header row of a list should be wrapped.  When set to N, the “…” notation will be used to denote that there is more text than can fit in the header cell and the mouse over will be provided to show the full text.

wrapHeaderText=Y

Defaults to N if not provided

linkColumnRefCode

Optional

If populated, will assume the contents of the column is the link to the Document in the Document Storage System and will render it as a hyperlink. If that column has no value, no link will be rendered.

linkColumnRefCode=
linkToDoc

linkColumnText

Required if linkColumnRefCode is set

This is the text to be used within the Hyperlink. It must be specified if a linkColumnRefCode is set

linkColumnText=View Document

idColumnReferenceCode

Required if a Detail property file is provided or a Delete button is configured

This is the column containing the ID for the document in the Document Storage System. This allows it to be referenced for editing and for deletion.

idColumnReferenceCode=id

isCrossProductView

Optional

If the list configuration is to be shared across multiple Product Groups, then it can be configured in the Cross Product Group. This property should be set to Y to indicate this.

By default, this property is set to N and the Lists View configuration will be local to the Web Page Template.

isCrossProductView=Y

Defaults to N if not provided

beginPagingThreshold

Optional

Indicates the point at which paging will become enabled. Until this threshold is exceeded the paging controls will not be shown.

NOTE: Unlike other lists there is no enableScrolling aspect to this property as scrolling is not enabled.

beginPagingThreshold=10

Defaults to 15 if not provided

maxRowNumber

Optional

If the number of rows exceeds this amount, then the data will be cut off and only the maximum number will be displayed.

maxRowNumber=100

Defaults to 200 if not provided
