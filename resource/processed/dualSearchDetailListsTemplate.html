CoreSuite NAPC : dualSearchDetailListsTemplate

Created by Susan Wilson, last modified on 20 Nov, 2019

Search Detail + Dual Lists Template

This Template supports the use of an Alternate Menu container as well as a configured Detail View to manage the detailed search criteria provided by the user. Two configured List Views will be used to display the returned list of results from the search.  


Detail Property File 

A Detail property file is required for the initial Detail component of the template that specifies the information required to render the View in the Detail Adaptive Unit.  These properties are consistent with the properties supported by the original Search Detail + List template. 


In addition to the Standard Detail properties, the properties below will be supported for this part of the template. 

Property Parameter 

Example Values 

Description 

Comments 

hideSearchDetailUnit 

(Optional) 

Example:  hideSearchDetailUnit=Y 

Hides the Search Detail and automatically executes the Search ID configured on the Search button on the View. 

Available when the target entity is 30000 

This is used with the Launch Search Function Type used from within a traditional list Adaptive Unit.  When the Function Type is used, the Function Type target is the target Alternate menu Container code. 

 


hideSingleTab 

(Optional) 

Example:  hideSingleTab=Y 

Hides the container on the left side that holds the menu links of the Search webpages within the Search Group.  

When set to Y on any web page that comes into context, the menu/navigation target container will be hidden.  Only the setting on the current page’s property file will be used to determine if the menu should be hidden.  When multiple pages are in the same container care should be taken to set their properties in a consistent manner..

 Hidden Detail

When a user selects a row from the top list, the data in that row is mapped to a hidden Detail View that is never shown to the user.  The hidden Detail is defined by a Detail View configured and referenced in the appropriate property file in the configured web page.  The information from the selected row will be mapped to the Detail via Q-tags on the corresponding View Items. 

The hidden Detail property file supports most standard Detail properties where the function makes sense to the template structure.  Because the Detail View is never shown to the user, many of those properties do not apply in the new template.

 Secondary List

The property file supports most standard List properties where the function makes sense to the template structure.  Only a displayType of List is supported for this template.  The list will display information only, so any View Item Actions in it will be ignored.  The list is not selectable, nor will it support paging, filtering, or sorting.
