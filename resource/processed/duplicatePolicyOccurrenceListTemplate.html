CoreSuite NAPC : duplicatePolicyOccurrenceListTemplate

Created by Susan Wilson, last modified on 19 Nov, 2019

 

Web Page Property files are used to control the settings required for the various Templates configured as Web Pages.

 

The Policy - Duplicate Occurrence Error Summary Template uses Custom Duplicate Occurrence List Properties that must be named and configured as follows:
duplicatePolicyOccurrenceList.properties
Property Name
Values
Behavior
Required?

presentationType

DuplicateOccurrenceList

Example:

presentationType= DuplicateOccurrenceList

Indicates that the presentation Type is a DuplicateOccurrenceList which extends the FieldLevelErrorList

Yes

errorMessageText

Simple HTML

Example:

errorMessageText=<B>The following pages were found to have duplicate Policy Occurrences. 

The links below provide easy navigation to the corresponding pages.<BR><BR><U>Note:</U> 

he contents of this page will refresh upon Rating or Issuing<B><BR>

Provides an error message to the user at the top of the page.

No

flcPagingThreshold

Numeric

Example:

flcPagingThreshold=1000

Indicates at what point the list of occurrences should start "paging".

Default = 1000

No
