CoreSuite NAPC : establishNewConfigVersion

Created by Former user, last modified on Dec 05, 2019

Establish New Configuration Version

DescriptionThis method will use the standard Configuration Version selection logic to determine if the Configuration Version on the policy transaction should be changed from what is currently selected and if so, will associate the transaction with the new Configuration Version and run Rule Reapplication to apply the product rules in the new Configuration Version to the transaction in context.
Supported Action TypeStandard
ConstraintsMust be run from within a Policy Transaction context.
Suggested DependenciesNone
NotesNone

 

XML Usage

This method requires generated XML that provides the fields necessary as input to the selection of the Configuration Version. An example of the questions that should be included is:
Product Group30000_1
Reference Date30000_36
Override Reference Date30000_136
Product Group Reference30000_137
Original Reference Date30000_139
Selective Testing Group30000_175

Attributes

Because this method invokes Rule Reapplication if the Configuration Version changes, it requires the same Attributes as the Rule Reapplication method:

  • Interface Tag - defines the scope of the information to have rules reapplied.

  • Suppress Errors Indicator - Determines behavior when errors are discovered.

Return Codes

Return Code
Description
1New Configuration Version found; If configured, Rule Reapplication ran successfully and completed with no updates to the policy
2New Configuration Version found; Rule Reapplication configured and ran successfully and completed with messages for the Administrator only
3New Configuration Version found; Rule Reapplication configured and ran successfully and completed with policy updates and messages for most users
4New Configuration Version found; Rule Reapplication configured and ran successfully and completed with informational messages only
5Failure - No MC, CT, Version in context
6No change in Configuration Version
7Failure - Unable to determine Configuration Version.
8New Configuration Version found; Rule Reapplication failed due to a failure in the Action called on Submit of a View.
-1Unspecified Failure
