Evaluate Co-Occurrence Rules

DescriptionEvaluates the specified set of Co-Occurrence Rules against the policy transaction in context and creates policy errors if violations are found.
Upon completion, the page to be navigated to will be provided by the Step Outcome.
This method expects an Attribute which contains the XSLT file of "EvaluateCoOccurrenceRules.xsl".
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested Dependenciesremoval_code <> P (Pending Removal) or R (Removed)
NotesAny Step that uses this method should be immediately followed by an upload (Update Policy Transaction) Step that takes any errors returned by this method and adds them to the transaction.

 

XML Usage

This method requires generated XML that contains the information necessary to validate the coverages. Traditionally the XML is generated using the RATING interface.
