CoreSuite NAPC : evaluteOutcomes

Created by Former user, last modified on Dec 05, 2019

Evaluate Outcomes Only

DescriptionThis method does nothing. It is used to allow the evaluation of Outcomes during an action with no activity on the transaction itself. It can be used at the end of an action to allow Outcomes to check the results of multiple steps in combination or it can be used early in an Action to validate the conditions that may exist and provide a detailed message back to the user regarding why the Action may not be called.
