Execute Formula

DescriptionThis method allows the current Action to invoke a Control Formula as part of its execution.
Supported Action TypeStandard
ConstraintsThe Control Formula CODE Attribute must refer to a Formula which is defined to be a Control type.
Suggested DependenciesNone
NotesNone


XML Usage

None

Attributes

This method requires the code of the Control Formula to be called configured as an Attribute

Return Code
Description
