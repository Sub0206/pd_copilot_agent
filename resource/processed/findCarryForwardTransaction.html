Find Carry Forward Transaction

DescriptionThe method looks for the latest active (open or closed) Carry Forward transaction (PC/GN effective on the same date as a Renew with originating ID specified) created as a result of issuing an OOS transaction, and sets it into context for the user and subsequent Steps in the Action.
The Action which calls this method (used in the case of an OOS acknowledgement page) could then navigate to a specified page using the navigation capabilities of Actions and Outcomes.
If there is no Carry-Forward transaction, or there is no policy transaction in context, an error indication is returned using the Return Codes from the method.
Supported Action TypeStandard
ConstraintsMust be executed from within a policy transaction context.
Suggested DependenciesNone
NotesNone
