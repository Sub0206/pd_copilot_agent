Find End of Term Policy Transaction

DescriptionThe Find End of Term Policy Transaction method uses the Transaction Effective Date specified in the Input XML to identify the specific term of interest on the policy in context. Then it selects the policy transaction that represents the state of the policy at the end of the term. The method selects the latest active issued bypass or regular category policy transaction in the identified term (which may be effective later than the input date).
If no effective date is provided in the input XML, it will put the latest active issued regular or bypass-category transaction on the policy into context.
Supported Action TypeStandard
ConstraintsMust be executed from within a policy context.
Suggested DependenciesNone
NotesTypically used to support Policy Inquiry for end of term processing using Policy Number or MC-ID only without a specific CT/Version.

 

XML Usage

This method expects update XML with a Transaction Effective Date using the XML tag for question 30000_143. It will use that date to identify the correct transaction to put in context.
