Find Incomplete OOS Transaction

DescriptionThe method looks for an incomplete OOS transaction (marked with an OOS Completion Code = O), and sets it into context for the user and subsequent Steps in the Action. The Action which calls this method could then be used to issue the corresponding replacements using the navigation capabilities of Actions and Outcomes. If there is no incomplete OOS transaction, an error indication is returned using the Return Codes from the method.
