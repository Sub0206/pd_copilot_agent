CoreSuite NAPC : findRemovedRenewal

Created by Jagadish Rotti, last modified on Feb 18, 2020

Find Removed In-Process Renewal

Description

Uses the current transaction in context to identify an associated removed in-process Renewal policy transaction to be set into context for subsequent processing by the Action.  The Renewal selected will be identified as one that was removed by the issuance of the transaction in context and is associated to the current transaction’s identifiers in the Contract Transaction table.

The transaction selected will have a Transaction Type of RENEW with a Transaction Status of Open (O), a non-null Removal Code, a REVERSING_TRANSACTION value that matches the CT ID of the current transaction in context, and a REVERSING_VERSION_NO that matches the current transaction’s value.

If multiple versions of a Renewal match the criteria above, the process will select the one with the lowest Version Number.

Once a transaction is identified, the CV selection will be executed to put the correct CV in context for the renewal term.  The definition of the currently executing Action will not be changed and will continue using the original image loaded when the Action began.  Any Views or Interfaces used once the CV has been updated will be taken from the new CV.  This behavior is consistent with how Renewal transaction creation and the Establish New CV Internal Method currently behave.

Can be used to recreate the changes from a removed Renewal transaction on a new Renewal transaction.
