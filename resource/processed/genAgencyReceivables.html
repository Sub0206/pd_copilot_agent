CoreSuite NAPC : genAgencyReceivables

Created by Jagadish Rotti, last modified on Dec 12, 2022

Generate Agency Bill Receivables

Description

This method will process an algorithm that will generate receivables for Agency Bill from Policy Transactions governed by Pay Plan Installment Lines of the Policy.  The algorithm will perform the generation based on the set of Policy Transaction IDs passed to it but if there are no Policy Transaction IDs passed then the IDs are searched for the Account in context and all that match the necessary criteria are processed.
