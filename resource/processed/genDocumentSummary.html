CoreSuite NAPC : genDocumentSummary

Created by Sharmila B, last modified on May 13,2025

Generate Document Summary

Description

This method allows the Document Management template to have a Document Summary button configured that will generate a summary of the selected document.

Supported Action Type

Standard Action

Constraints

A Document must be selected and this Internal Method is limited to the Document Management page

Suggested Dependencies

On the button configured to call this Action, it is recommended to add dependencies to limit the call to appropriate document types and to not call it for generated Document Summary.

None
