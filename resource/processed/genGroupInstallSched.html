CoreSuite NAPC : genGroupInstallSched

Created by Jagadish Rotti on Mar 17, 2022

Description

This method will process an algorithm that will update the installment schedule information for a group policy in a Group Billing Account. 

Supported Action Type

Standard

Constraints

Must be executed from within the Sapiens Billing System

Identifies the Question that holds the Offset Days used to determine the Due Date. 

This is an optional attribute, if the attribute is missing the Offset Month logic is used for Due Date determination.  If the attribute exists and a value is present, the Offset Days logic will be used.

If the Billing Day Indicator is set to ‘Y’, the Offset Days calculation of the Due Date for the Receivable will respect the Due Day of the Policy.  If the Offset Days added to the Effective Date of the Policy is less than the next Due Day, the Date is moved forward to that date using that Day; otherwise the date is moved backwards to the next due day date.
