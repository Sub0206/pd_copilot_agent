Created by Jagadish Rotti on Nov 09, 2023

Get Accounting Period

Description

 This method will extract the Accounting Period information from the Accounting Period Date to Use table and based on the provided attributes, the Billing Account will have Questions updated with the information.

Supported Action Type

Standard

Constraints

Must be executed from within the Sapiens CoreSuite Applications
