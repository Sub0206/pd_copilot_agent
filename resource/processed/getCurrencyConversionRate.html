Get Currency Conversion Rates

DescriptionThis method is a View Action method that will accept an Accounting Currency, Original Currency, Exchange Rate Date, and a Writing Company and return conversion rates (Accounting and Original Rates). These rates can be used to convert limits, deductibles, and premiums to capture additional information to support multiple currencies. This service uses the WritingCompanyExchangeRates table to return the exchange rates.
Example input XML: < policyCoverage> <accountingCurrency LITERAL="United States Dollars">USD</accountingCurrency> <originalCurrency LITERAL="United States Dollars">USD</originalCurrency> <currencyExchangeRateDate>07/29/2010</currencyExchangeRateDate> <COMPANY LITERAL="Stellar Canada">CAN</COMPANY> <baseCurrency>CAD</baseCurrency> < /policyCoverage>
Example output XML: < viewXML> <returnCode>2</returnCode> <returnReasonCode>0</returnReasonCode> <answerSets> <question XMLTAG="currencyConversionRateRtnCd"> <selectedAnswerValue>1</selectedAnswerValue> </question> <question XMLTAG="accountingCurrencyExchangeRate"> <selectedAnswerValue>0.8250</selectedAnswerValue> </question> <question XMLTAG="originalCurrencyExchangeRate"> <selectedAnswerValue>0.8250</selectedAnswerValue> </question> </answerSets> < /viewXML>
Supported Action TypeDetail View
ConstraintsNote that the service requires input XML tags for accountingCurrency, originalCurrency, currencyExchangeRateDate, COMPANY, and baseCurrency (as seen above).The example above shows a policyCoverage parent node.This node may vary (i.e. locationCoverage, vehicleCoverage, etc.).
Suggested DependenciesAll of the input variables should be present.
NotesRates should be entered in the WritingCompanyExchangeRates table
