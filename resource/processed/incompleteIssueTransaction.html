Mark Transaction as Incomplete Issue

DescriptionSets and resets the status value for a transaction in context to P (Pending Issue) to indicate that the transaction is in the process of being issued in the downstream system.
If a policy has any transaction with a Status of P the entire policy is locked due to a possible out of sync condition with the downstream system(s).
Supported Action TypeStandard
ConstraintsNone
Suggested DependenciesNone
NotesNone

 

XML Usage

None

Attributes

Name
Values
Behavior
ACTIONSET RESETWhen ACTION=SET
  • Sets the Status value of the policy transaction in question 30000-40, on the contract_transaction table to Incomplete Issue (P).
  • Sets the value of the Status in the search information associated with the policy to Incomplete Issue (P) to support retrieval of policies identified as being in an Incomplete Issue status.
    When ACTION=RESET
  • Sets the Status value of the policy transaction to Open
  • Updates the Status value in the search information to Closed for issued policies, and Open for quotes/Applications.
