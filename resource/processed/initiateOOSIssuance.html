Initiate OOS Issuance

DescriptionThis method allows the user to declare their intention to issue the OOS transaction. The method will mark the OOS transaction with an OOS Completion Code of O and lock the policy to prevent any new transaction creation or change processing.
Supported Action TypeStandard
ConstraintsMust be executed from within an OOS policy transaction context
Suggested DependenciesNot available if Incomplete OOS Policy Fact is true.
NotesThis method is called by configuration when the user attempts to issue an OOS transaction.

None
