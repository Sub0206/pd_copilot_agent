Issue OOS Replacements

DescriptionThis method will issue the replacement transactions created by OOS processing for each issued transaction that is being replaced relative to the OOS transaction in context. The method will reset the removal_code and oos_completion_code for all of the impacted transactions to null. This method does not execute any configured behavior. It will simply find all replacement transactions that are replacing issued transactions as a result of the processing of the OOS transaction in context and mark them as issued in PolicyWriter resetting the removal_code and oos_completion_code as well and making any necessary updates to the search information cache.
Supported Action TypeStandard
Constraints
  • Must be executed from within an OOS policy transaction context.
  • Not available for use by an OOS Cancel transaction.
Suggested Dependencies 
NotesThis method is called during the issue of an out of sequence transaction and uses a Dependency which checks the return code from the Process OOS Replacements method or the OOS Indicator Policy Fact.
