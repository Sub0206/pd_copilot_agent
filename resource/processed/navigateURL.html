CoreSuite NAPC : navigateURL

Created by Former user, last modified by Jagadish Rotti on Oct 19, 2021

Navigate to external URL

DescriptionNavigate the Account Manager user to an external URL either through a popup window or through the current window (if method is POST). If included, Attributes or an XSL can be used to add parameters to the URL.
Supported Action TypeStandard
ConstraintsThe complete URL cannot exceed 2083 characters.
Suggested DependenciesIf using a QTag, make sure the QTag is present.
Notes

The URL parameter that can be specified can either reference a QTag such as Q_30000_1234, a JNDI entry such as url/externalSystemX or a hardcoded value such as https://www.google.com.

If using a QTag, it must be held at the 30000 level.

If the Step attribute "Create Parameters via XML" (20008-62) is set to Yes on the Step that calls this method, then all Attributes on that Step will be ignored and the result of the XML generation and XSL will be used to provide the parameters for the navigation. 

Depending on the service, the XSL can provide the output string in the ?[name]=[value]&[name]=[value]&[name]=[value] format or possibly as a URL continuation such as /vehicles/1234. The output of the XSLT will not be validated, it will simply be appended to the resolved URL.


XML Usage

XML can optionally be used to feed an XSL that produces the navigation parameters for the URL based upon the Step property.  The XSL output can be in the format ?[name]=[value]&[name]=[value]&[name]=[value] or as a URL continuation such as /vehicles/1234. The result of the XSLT will be appended to the resolved URL.

Attributes

Attributes are optional, and if included will be appended to the URL using the Name as the parameter name and the Value as the parameter value using this format: &[name]=[value]; One exception to the norm is if the Attribute Name is "XML" then the Value text (assumed to be XML) is added using a parameter name of POLICYXML.

Attributes will be added in the order specified by the Attribute Sequence configuration.
