CoreSuite NAPC : performPolicyTransfer

Created by Former user on Oct 25, 2019

 Perform Policy Transfer

DescriptionThis method will transfer a Policy from one Billing Account to another.  The existing non-zero balances will be adjusted off the original account and recreated based on the algorithm’s logic on the new account.  The transferred Policy will be updated through the Policy Transaction Staging Table to allow subsequent transactions to process.
Supported Action TypeStandard
ConstraintsCan be executed from within the Adaptik Billing System or via a webservice call provided by the Adaptik Billing System.
Suggested DependenciesNone
Notes

An Account ID must be provided

 

XML Usage

Accept XML for Update
