Policy Number Block Assignment

DescriptionUsing the input attribute which designates a policy block to use, the algorithm will find the appropriate block and the last number used and assign the next number (increment by 1) to Question 30000_160.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesQ_30000_160 is Absent AND
removal_code Is Absent
NotesNote that when this method is called and if a number is taken from a block, the change is committed and will not be impacted or rolled back within the transaction if rolled back (by an outcome).


XML Usage

None

Attributes

Seq #CodeValueTypeDescription
10CODEQ-tag i.e. Q_30000_##StringIndicates which Q-tag will contain the logical policy number block code should be used when retrieving the next number.

Return Codes

Return CodeDescription
1Success
2Failure - No MC, CT, Version in context
3Warning - the specified block is running out of policy numbers
4Error - there are no more policy number available within the block
-1Unspecified Failure
