Process OOS Changes

Description

This method manages the process by which Out Of Sequence (OOS) changes are pushed forward to subsequent transactions after an OOS transaction is issued.

The application property of oosFlatCancelCommit will control whether or not the code commits after the flat cancel is created on the future term.

Supported Action TypeStandard
ConstraintsNone
Suggested DependenciesNone
Notes

This method is called during the issue of an out of sequence transaction and uses a Dependency which checks the return code from the Mark Transaction as Closed method or the OOS Indicator Policy Fact.

If the oosFlatCancelCommit application property does not exist or is set to N, there will not be an auto-commit performed.  In order to mimic pre 10.5 functionality, the application property should be set to Y.


XML Usage

None

Attributes

The Process OOS Changes method requires a single attribute to be specified which indicates the code for the OOS Action Macro that is to be run on any issued transactions that are replaced during the change processing or any automatic flat cancels created during cancel processing.
