Process OOS Replacements

DescriptionThis method manages the process by which Out Of Sequence (OOS) changes are pushed forward to subsequent transactions after an OOS transaction is issued.
The method will create replacement transactions for any subsequent transactions relative to the OOS transaction in context when it is required that the user be able to review and alter the replacements created prior to their issuance. Once the replacements have been created, the appropriate Action Macro will be run on the replacement transaction.
Supported Action TypeStandard
Constraints
  • Must be executed from within an OOS policy transaction context.
  • Not available for use by an OOS Cancel transaction.
Suggested Dependencies
NotesThis method is called during the issue of an out of sequence transaction and uses a Dependency which checks the OOS Indicator Policy Fact.


XML Usage

None

Attributes

The Process OOS Replacements method requires two attributes to be specified which indicate the code for the OOS Action Macros that are to be run on the transactions that are replaced during the change processing triggered by the OOS transaction. The first Macro specified will be used on replacements for issued transactions and any created carry-forward transactions while the second Macro specified will be run on replacements for in-process transactions.

Return Codes

Return CodeDescription
1Success
2Transaction in context is not OOS
3Transaction in context is a Cancel transaction
4Failure - No MC, CT, Version in context
5Rule Reapplication failed on a carry forward transaction
6Rule Reapplication failed on a replacement transaction
7OOS Action Macro failed for Carry Forward with no subsequent transactions
8OOS Action Macro failed for Carry Forward with subsequent transactions
9OOS Action Macro failed for replacement transaction
10Failed - OOS Code not set
11Success - No Replacements needed
12The method was invoked when there were existing replacements, but there was no restart transaction (transaction with OOS Completion Code A or T or a removal code of M).
-1Unspecified Failure
