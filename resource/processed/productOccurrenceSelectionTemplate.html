Product Occurrence Selection

The Product Occurrence Selection Template uses the Product Selection Policy List Properties for policy occurrences, the Product Selection Product List Properties for product occurrences, the Standard Detail Properties for Parent Detail (shared between DLD & UPD schedules when both selected), the List Properties, the Detail Properties, and/or the Updateable List if Updateable List Schedule is included.

scrollingEnabledOptionalY, N
Example:

Note that if enableReordering=Y, then scrollingEnabled must be set to Y.

Default = N		 
beginPagingThresholdOptionalWhole Number
Example:
beginPagingThreshold=50		Indicates the number of occurrences for the entity before paging is enabled (greater than or equal to) when scrollingEnabled=Y. Also indicates when filtering and sorting functionality is performed on the server vs on the client. If scrollingEnabled=N, then the paging section will not be displayed unless the number of entity occurrences surpasses this threshold OR the viewable area for the list cannot display the specified number of occurrences. Note that the maximum number this property can contain is 300. An application exception is given to the user if a higher number is specified.

Default = 200 if scrollingEnabled=Y

Default = 5 otherwise

Note that if enableReordering=Y, then beginPagingThreshold will be ignored.

Note that if enableReordering=Y, then enableFiltering must be set to N.

Default = N
