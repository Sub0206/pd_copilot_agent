CoreSuite NAPC : reconcilation

Created by Former user on Oct 25, 2019

Run Manual Agency Reconciliation

Description 

This method will validate that the policy number for the items selected in the working statement match the policy numbers for the items selected in the Target Statement. 

The system will validate that the sum of the Premium for the Item(s) selected in the working statement equals the sum of the Apply Premium for the items selected in the target statement. 

The system will validate that the sum of the commission for the item(s) selected in the working statement equal the sum of the apply commission for the items(s) selected in the target statement. 

If on the target statement, the gross premium and commission amounts match the apply premium and the apply commission amounts, the system will default the status of the item(s) in the working statement and the target statement to "Reconciled". 

If the gross premium on the target statement matches the apply premium but the commission amounts do not match, the system will default the status of the working statement item(s) to “Reconciled” and the target statement item(s) to "Reconciled with Commission Differences". 

If the gross premium on the target statement does not match the apply premium but the commission amounts do match, the system will default the status of the working statement item(s) to “Reconciled” and the target statement item(s) to "Reconciled with Premium Differences". 

The system will update the “Reconciled Premium” column for each selected item with the Apply Premium amount.   

The system will update the “Reconciled Commission” column for the selected items with the “Apply Commission” amount. 

The system will clear the Apply Premium and Apply Commission amounts for the selected items.
