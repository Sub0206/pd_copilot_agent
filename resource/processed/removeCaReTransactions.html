CoreSuite NAPC : removeCaReTransactions

Created by Jagadish Rotti on Mar 17, 2022

Remove Cancel/Reinstate Transaction Pair

Description

Uses the current transaction in context to identify a pair of Cancel/Reinstate transactions and set the Removal Code value on them to “R”.  

The transactions must be part of a pair that have the same Transaction Effective Date where the Reinstate has a CT ID greater than the Cancel transaction.

Supported Action Type

Standard

Constraints

The transaction in context must be either a Reinstate or a reinstated Cancel.  If a Cancel is selected that has not been reinstated, the method will not remove the transaction and an error is returned.

Suggested Dependencies

None

Attributes

None

Notes

Can be used to remove the no longer active Cancel and Reinstate transaction pair.  Note that upon completion, it is recommended that the Transactions page is the target page as this will have the removed transaction in context.  The user may now choose a new transaction to place into context for further processing of the policy.


XML Usage

None

Return Codes

Return Code

Description

1

Success – Transactions removed

2

Failure - Transaction in context is neither a Reinstate nor a reinstated Cancel transaction

-1

Unspecified Failure
