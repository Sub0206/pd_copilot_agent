Repeal OOS Changes

DescriptionThis method allows the user to abandon an attempt to issue a set of replacement transactions created as a result of OOS processing.
The method will physically delete any of the pending replacement transactions identified by a Removal Code of A or M and will update any pending replaced transactions identified by a Removal Code of P by setting their Removal Code back to null. The method will also reset to null any OOS Completion Codes on any remaining transactions.
Supported Action TypeStandard
Constraints
  • Must be executed from within an OOS policy transaction context after the replacement processing has been performed.
  • Not available for use by an OOS Cancel transaction.
Suggested DependenciesNot available if Incomplete OOS Policy Fact is false
NotesThis method is called by configuration when the user clicks the Cancel button from within the new OOS Transaction Summary page.
