CoreSuite NAPC : reportsListTemplate

Created by Susan Wilson, last modified on 20 Nov, 2019

 

The Report List Template consists of two List Units
The first List Unit will be used to display all the reports within the system that a user has access to (access is determined through integration with the reporting utility and exposed in the user Auth XML by their Role). 
The second list presents a list of report output files that have been processed and saved for the selected report of the first List.
(PLEASE NOTE: this template may be used withing the Policy component BUT it must be used in context of a Configuration Version as it requires a configured Web Page.)

Indicates if the filter row should be enabled or disabled. When property is present and set to N, the filter row will be hidden from the user

beginPagingThreshold

O

beginPagingThreshold=15

Indicates the number of occurrences for the entity before paging is enabled (greater than or equal to) when scrollingEnabled=Y. Also indicates when filtering and sorting functionality is performed on the server vs on the client. If scrollingEnabled=N, then the paging section will not be displayed unless the number of entity occurrences surpasses this threshold OR the viewable area for the list cannot display the specified number of occurrences.  Note that the maximum number this property can contain is 300. An application exception is given to the user if a higher number is specified.

Default=200, if scrollingEnabled=Y
  
Default=5
