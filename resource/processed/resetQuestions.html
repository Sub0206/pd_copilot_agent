Created by Former user on Oct 25, 2019

Reset Question Values (View Action Only)

DescriptionThis method provides a mechanism to reset question answers to the default value specified on the View. If no default value is specified, the answer will be set to Missing.
Supported Action TypeView Action
ConstraintsMust be executed from within a Policy Transaction context.
May be used by View Actions only.
Suggested DependenciesPolicy Status = Open
removal_code <> P (Pending Removal) or R (Removed)
NotesNone


XML Usage

None
