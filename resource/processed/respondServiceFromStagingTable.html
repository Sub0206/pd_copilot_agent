CoreSuite NAPC : respondServiceFromStagingTable

Created by Jagadish Rotti, last modified on Mar 26, 2024

Respond to Calling Service from Staging Table

Description

Uses the current transaction in context and uses the CATEGORY attribute to pull the payload stored in the XML/JSON Staging table.  If there are multiple rows on this table, for the same MC, CT, Version, and Category, then the LAST_UPDATE_TIMESTAMP will be used to find the last record stored.   This payload will then be used to return to a service call similar to the existing “Respond to Calling Service”. 

Supported Action Type

Standard

Constraints

There must be an MC, CT, and Version number set into context for the method.

Suggested Dependencies

None

Notes

This internal method can be paired with a second step that responds to the calling service IF the staging table does not contain an xml/json payload. 

XML Usage

None

CATEGORY – the Category that should be used to retrieve the staged record.
