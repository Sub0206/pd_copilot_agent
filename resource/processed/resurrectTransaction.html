Resurrect Transaction

DescriptionResurrects the transaction in context by resetting the removal code and timestamp values to null on the contract_transaction and alternate_query tables as well as in the session.
Supported Action TypeStandard
ConstraintsMust be executed from within an open (un-issued) new-business like Policy Transaction context which has a non-null removal_code.
Suggested DependenciesPolicy Status = Open AND Transaction Type = NB, REWRITE
NotesNone


XML Usage

None

Attributes

None

Return Codes

Return CodeDescription
1Success
2Failure - No MC, CT, Version in context
3Failure - Transaction in context (or another version of it) is issued or not new-business like or does not have a non-null removal_code.
-1Unspecified Failure
