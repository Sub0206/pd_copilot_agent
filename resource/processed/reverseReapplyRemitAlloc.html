CoreSuite NAPC : reverseReapplyRemitAlloc

Created by Jagadish Rotti, last modified on Jun 28, 2021

Reverse and Reapply Remittance Allocations

Description

This method will process an algorithm that will identify if “offsetting” between a remittance over allocation (credit receivable) and a debit receivable should be done and then if yes, reverse the credit receivable and reapply to the debit receivables.

Standard
