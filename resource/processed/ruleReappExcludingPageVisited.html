CoreSuite NAPC : ruleReappExcludingPageVisited

Created by Former user, last modified on Dec 05, 2019

Perform Configured Views

DescriptionThis method forces the execution of a set of defined Product and Policy Configuration rules against the policy transaction identified by the current context. The method uses a set of Views defined in an Interface to apply the configured rules from the Views to the policy transaction.
The method will apply all Views to the transaction when there is a corresponding entity occurrence on the policy transaction for the View. No consideration will be given for whether or not the View was previously processed against the transaction. All Views in the Interface which have a corresponding occurrence will be processed. If there is more than one corresponding occurrence, all occurrences will have the View processed against them.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesThis method is not typically used by itself as an action, but as a step in a more complex Policy Action.
