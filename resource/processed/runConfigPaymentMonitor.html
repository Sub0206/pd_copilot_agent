CoreSuite NAPC : runConfigPaymentMonitor

Created by Former user, last modified by Jagadish Rotti on Jun 10, 2020

Run Configured Payment Monitor

Description

This method will use the provided attributes to create tracking events for a given policy based on the current standing of the policy (overdue) and its previously (or lack of) tracking events.

Supported Action TypeStandard
Constraints

Must be executed from within Adaptik Billing

Suggested DependenciesNone
NotesNone
