Created by Jagadish Rotti, last modified on May 15, 2023

Run Due Day Change

Description

This method will change the due dates for a given account/policy(ies) and adjust the balances for the original receivables.

Supported Action Type

Standard

Constraints

Must be executed from within the Sapiens BillingPro

Suggested Dependencies

None

Notes

None
