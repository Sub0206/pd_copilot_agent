CoreSuite NAPC : runInvoiceApproval

Created by Jagadish Rotti on Nov 26, 2020

Run Invoice Approval

Description

This method will process an algorithm that will search for all “Pending” invoices and approve the ones that have a Due Date that is either less than or equal the current date plus the invoice lead days parameter for the invoice’s policy.    

Supported Action Type

Standard

Constraints

Must be executed from within the Adaptik Billing System

Suggested Dependencies

None

Notes

None

None
