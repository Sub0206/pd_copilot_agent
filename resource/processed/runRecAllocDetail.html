CoreSuite NAPC : runRecAllocDetail

Created by Former user on Oct 25, 2019

Run Receivable Allocation Detail

Description  

This method will process an algorithm that will use the data from the current context and allocate portions of an allocation to the various Receivable Charges in the order specified by the allocation priority settings on the Policy.   The Receivable Charge occurrence will be updated with the allocated amount and new Receivable Charge Allocation occurrences will be created 

Supported Action Type

Standard Action 

Constraints  

Must be executed from within the Adaptik Billing System.  The ID in context must be that of a Receivable ID (30007). 

Suggested Dependencies  

None  

Notes  

This method is meant to be configured in the same Action creating the allocation or reversing an allocation.  An example of this is when a remittance is being allocated to a receivable an Upload Action is being invoked from the allocateReceivable internal method, this Upload Action will have a n Action step to call this new method after the Receivable has its occurrence marked via xsl and upload (ie updRemitAllocToRec)
