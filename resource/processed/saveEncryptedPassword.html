CoreSuite NAPC : saveEncryptedPassword

Created by Jagadish Rotti, last modified on Feb 28, 2020

Save Encrypted Password

Description

This method is used in order for a user to be able to set an initial password. This will take a specific QTag as an attribute that is expected to have the user’s choice of password in it.  This value will then be encrypted via bcrypt as a one way hash and stored in the PASSWORD column of the IPM_USER_AUTH table within AuthorityPro.

Supported Action Type

Detail View Action

Constraints


Suggested Dependencies

Check to make sure that the QTag being used for the password contains a value.

Notes

Once this method is run, the QTag should be cleared using another step immediately afterwards so that its original non-encrypted value does not get stored.
