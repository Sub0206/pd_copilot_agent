CoreSuite NAPC : saveToSession

Created by Jagadish Rotti, last modified on Feb 18, 2020

Save to Session

Description

This method will accept a list of Attributes that provide a list of session Questions within the current Detail View whose values in the View should be used to update the corresponding session variables from their Question Properties.

This allows user input data captured in an active Detail View to be persisted in the session without requiring that the View be submitted.

The method will loop through the provided attributes and for any Question listed that is configured in the current View, it will update the corresponding session variable with the value in the View Item.  Inapplicable, null or missing answers will be used to update their session variables to null.

Supported Action Type

View

Constraints

This method will only update session Questions.  If any of the Q-tags specified are not session Questions, they will be silently ignored.

Suggested Dependencies

None

Notes

Can be used to transfer values from the current active Detail view to a user’s session.

Useful in a cross-product context to recall values previously entered by a user when the active Detail View in use is being replaced.

Excessive use of session variables can cause inflated memory requirements in the application server.  Values should be thoughtfully defined.
