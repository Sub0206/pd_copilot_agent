Send Text Message

DescriptionThis method allows the configurator to construct a text message from the contents of the policy transaction in context and queue it for delivery to the specified recipients.
Supported Action TypeStandard
ConstraintsThe input XML (after the forward XSL) must correspond to the XML Structure described below.

File attachments and embedded images are not currently supported.
Suggested DependenciesNone
NotesThis method will place a text message request on the corresponding queue, but cannot track the final disposition of the message. It will indicate whether the item was placed on the queue successfully or not, but will not provide details on whether it was sent successfully.


XML Usage

This method requires the use of the following XML structure.

NameData TypeDescription
TextMessagecomplexTypeRoot node of the request structure.
MessageHeadercomplexTypeContainer element for the message header elements.
FromTextProvides the Number that should be used in the "from" aspect of the text message being sent.

The text messaging vendor being used to transmit the message may include restrictions on what numbers can be used as the "From" on text message requests, or override the value sent with something at the account level. No validation is done by the method however.
TocomplexTypeContainer element for the message recipient numbers.
NumberTextThe possibly repeating Number to be used to address the text message.
BodyTextThe body of the text message.

May contain only plain text.
Example:

<?xml version="1.0"?>
< TextMessage>
<MessageHeader>
<From>6105551212</From>
<To>
<Number>16256</Number>
<Number>6104441212</Number>
</To>
</MessageHeader>
<Body>This is a test. This is only a test. If this were a real text it would be more interesting.</Body>
< /TextMessage>

Attributes

None
