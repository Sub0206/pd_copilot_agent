Set Freeze Stage

DescriptionThis method sets the current policy transaction's Freeze Stage to the value provided. Specifically updates question 176 on entity 30,000 assumed to be Policy Freeze Stage as well as the Contract Transaction table.
Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesPolicy Status = Open
removal_code <> P (Pending Removal) or R (Removed)
NotesNone


XML Usage

None

Attributes

Stage - The integer value to be initialized into the Policy Freeze Stage.
