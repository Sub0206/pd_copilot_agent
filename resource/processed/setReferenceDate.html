Reset Reference Date

DescriptionResets the Original Reference date and depending on the values of Honor Quote Rules and Override Reference Date may also set the Reference Date used for Configuration Version selection.

The algorithm used to determine the Reference Date will set the Original Reference Date(30000_139) to the Process Date (30000_35) for Process Date States, to the Effective Date (30000_34) for Effective Date States, and to the earlier of the two for Early Date states. Once the Original Reference Date is set, it checks the Honor Quote Rules and Override Reference Date indicators and if both are set to N (No) (if they are not set at all, No is assumed) it will then copy the Original Reference Date into the Reference Date question.
