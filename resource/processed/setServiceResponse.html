CoreSuite NAPC : setServiceResponse

Created by Former user on Oct 25, 2019

Respond to Calling Service

Description

This method takes a generated XML that has been processed by an optional forward XSL and makes it available to be used in a response back to the invoking environment.  

If the Step has one or more optional ATTXPath Attributes, will use those to add any embedded file attachments to the XML provided by the Step. 

Supported Action TypeStandard & Detail View
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesProcessing Mode <> Online
Notes

Generally used in a web service context to create responses. 

Requires an XML Interface tag to use to generate response payload.


XML Usage

Generated XML will be used to respond to the calling environment.

Attributes

Code  

Value  

Type  

Description  

ATTXPath 

XPath value that identifies the XML Tag whose value will be replaced by the referenced attachment value 

String  

The optional Attribute may repeat for every XML tag that needs to contain an attachment in the XML 

The XPath should contain only the XML hierarchy from the root node that identifies the attachment tag.  No specifics regarding occurrences or identifiers should be included. 
The processing will search for every instance of the specified XML tag using the path specified and wherever the XML tags exists, the value, if it exists, will be replaced by the
referenced attachment in base64 encoded form.Attachment processing will be applied after any forward XSL has been processed and should reflect the XPath structure for the final XML. 

Return Codes
