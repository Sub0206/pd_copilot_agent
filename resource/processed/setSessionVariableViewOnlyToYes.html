Set Session Variable "viewOnly" to Yes

Description

Sets the “viewOnly” session variable to “Y” (Yes).

Supported Action Type

Standard Action and Action Macro.

Constraints

Must be executed from within a Policy Transaction context.

Suggested Dependencies

None.

Notes

The current page in Account Manager will remain displayed unless the Action's configuration specifies a navigation target..
