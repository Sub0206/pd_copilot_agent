CoreSuite NAPC : setStage

Created by Former user, last modified on Dec 05, 2019

Set Stage and Last to Specific Value

DescriptionSets the value of Stage and Last Stage to the value specified.
Supported Action TypeStandard
ConstraintsNone
Suggested DependenciesNone
NotesLast Stage is used only by the menu to make pages such as "Errors" available even if the stage has been further changed due to the user making changes to correct the listed errors.

Last Stage is normally set by an Action Outcome or completion at the same time that Stage is set. Stage is the value reflected on the policy transaction. Last Stage exists only under-the-covers and is not available to the user.


XML Usage

None

Attributes

Stage - The integer value to be initialized into the Policy Stage and Last Stage.
