CoreSuite NAPC : showPdf

Created by Former user, last modified on Dec 05, 2019

Create PDF

Description

This method includes both a file name and a file type with the PWDocument output created within the Action.  The file name will be derived from the XSL file name on the Step and simply match that file name with a different suffix of .pdf.  The file type will always be recorded as application/pdf for any file created by the method.

The resulting file created by the method available is a PWDoc:0 reference for Upload.

Supported Action TypeStandard
ConstraintsMust be executed from within a Policy Transaction context.
Suggested DependenciesNone
NotesRequires that an XML Generation I-Tag (Interface) be specified on the Step Detail page.
May require Adaptik intervention to ensure PDF output format meets business need.

 

XML Usage

Requires generated or reused XML be provided to the method.
