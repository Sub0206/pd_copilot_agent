CoreSuite NAPC : stackedCoverageTemplate

Created by Susan Wilson on 25 Oct, 2019

 

The Stacked Product Occurrences Template uses Custom Stacked Product Occurrence Properties that must be named and configured as follows: 

Property Parameter
Usage
Example Values
Description
Comments
presentationTypeRequiredMust Be Set to StackedCoverage
Example:
presentationType= StackedCoverage		Tells Account Manager the appropriate template to use. 
parentDetailViewRequiredValid View Tag
Example:
parentDetailView=polForVehCovDT		View tag will be used to capture policy questions that will be used to generate policy and vehicle coverages 
childListViewNameRequiredValid List View Tag
Example:
childListViewName=vehicleLT2		View tag will be used to get a list of child occurrences of policy. Must be view on same entity as childOccurrenceDetail. 
childOccurrenceDetailRequiredValid Detail View Tag
Example:
childOccurrenceDetail=vehicleForCovDT		View tag will be used to display occurrence questions on the page. Will also be used to generate occurrence coverages.Must be on same entity as childListViewName
childLinkedOccurrenceListRequiredValid Contract List View
Example:
childLinkedOccurrenceList=policyCoveragesLT		View tag will be used to get a list of child occurrences (policy coverages) that are already attached to the policy.Must be on same entity as childLinkedOccurrenceDetail
childLinkedOccurrenceDetailRequiredValid Contract Detail View
Example:
childLinkedOccurrenceDetail=policyCoveragesDT		Gives the default view to be used for each policy coverage (Note: this can be overridden for each coverage using an alternate view).Must be on same entity as childLinkedOccurrenceList
childLinkedOccurrenceDetailInitialQuestionRequiredValid Q Tag
Example:
childLinkedOccurrenceDetailInitialQuestion=Q_30003_1		Gives the B Tag of the Code question that links to the product occurrence list. Used while creation of child coverages. Policy coverages in above example.Must be on same entity as childLinkedOccurrenceDetail
grandChildLinkedOccurrenceListRequiredValid Contract List View
Example:
grandChildLinkedOccurrenceList=vehicleCoveragesLT		View tag will be used to get a list of grand child occurrences that are already attached to the policy.Must be on same entity as grandChildLinkedOccurrenceDetail
grandChildLinkedOccurrenceDetailRequiredValid Contract Detail View
Example:
grandChildLinkedOccurrenceDetail=vehicleCoveragesDT		Gives the default view to be used for each vehicle coverage (Note: this can be overridden for each coverage using an alternate view).Must be on same entity as grandChildLinkedOccurrenceList
grandChildLinkedOccurrenceDetailInitialQuestionRequiredValid Q Tag.
Example:
grandChildLinkedOccurrenceDetailInitialQuestion=Q_30007_1		Gives the B Tag of the Code question that links to the product occurrence list. Used while creation of grand child coverages. Vehicle coverages in above example.Must be on same entity as grandChildLinkedOccurrenceDetail
productListViewRequiredValid Product Occurrence Lists View Tag.
Example:
productListView=prodCovStackedLT		Gives the Product List to be used to get available coverages for policy and vehicle coverages. 
productListFilterColumnRequiredText
Example:
productListFilterColumn=Filter		Gives the Product Occurrence Reference Code used to identify the filter column. 
productListFilterValueRequiredText
Example:
productListFilterValue=LIAB		Gives the value that should be used to filter the Product Occurrence List for this page. 
productListCodeColumnRequiredText
Example:
productListCodeColumn =Code		Gives the Product Occurrence Reference Code used to identify the code (occurrence ID) column. 
productListParentCodeColumnRequiredText
Example:
productListParentCodeColumn=Parent		Gives the Product Occurrence Reference Code used to identify the Parent Code (occurrence ID) column. 
RightCodeColumnRequiredText:
Example:
RightCodeColumn =Coverage		Identifies code column from the contract list view (grandChildLinkedOccurrenceDetail) 
productListTargetQTagRequiredValid Product Q-tag
Example:
productListTargetBTag=Q_20004 _1		Provides the Product Occurrence Q-tag. Should correspond to the Product Occurrence List Q-tag. 
setStageDeleteRequiredValid Stage values (100, 300, 900, etc)
Example:
setStageDelete=300		Upon submit of the page, if the current stage value for the policy is greater than the property value and a question value has changed which causes a coverage to be added/deleted, then the current stage will be set to the property value specified.
childListPresentationDelimiterOptionalDelimiter values.
Examples include : ; -		Delimiter for presentation of the list columns for each vehicle.If not present, then a space will be used by default.
productListQuoteAlternateViewColumnOptionalText
Example:
productListQuoteAlternateViewColumn=Qt_Alt_View		Gives the Product Occurrence Reference Code used to identify the Quote Alternate View column. 
productListAppAlternateViewColumnOptionalText
Example:
productListAppAlternateViewColumn=App_Alt_View		Gives the Product Occurrence Reference Code used to identify the App Alternate View column. 
removeParentCoverage_QTagOptionalValid Q Tag.
Example:
removeParentCoverage_QTag=Q_30006_60		Q Tag of the question driving the applicability of the parent view. This question will be searched for under every child occurrence 
removeParentCoverage_QualifyingAnswerOptionalValid answer value:
removeParentCoverage_QualifyingAnswer=Y		Answer value of the child view question. When every child occurrence's answer matches this value, parent view will be hidden with the answer values of it's individual questions erased. 
rendererType OptionalTabularFormat Optional field that will allow changing the renderer for the Stacked Product Occurrence Template from the standard vertical view into the new Tabular Horizontal view. 
 
If this property is not provided, the default behavior will be to use the existing vertical renderer
literalColumnWidthOptionalExample: 200px or 20rem 

A value including the unit of measurement that will be used to govern the width of the first column that contains the literal. 

If this value is not provided, it will default to 30rem as supplied in the base CSS theme. This can be overridden at a custom theme level if needed


maxControlColumnsOptionalExample: 4 

A numeric value to indicate the number of occurrence control columns displayed between the two arrows before scrolling is needed. Once the number of occurrences exceeds this value, the arrows will become applicable so that occurrences can be scrolled between. 

If not specified, this will default to 3 columns


coveragesLiteralOptionalExample: Coverages

The literal displayed in the top-left corner where the occurrences and literals intersect. 

If not specified, no text will be displayed


emptyMessageOptionalExample: There are no vehicles available

The literal text displayed in place of the Tabular Grid if there are no occurrences available to set coverage information for.  

If not specified, no text will be displayed
