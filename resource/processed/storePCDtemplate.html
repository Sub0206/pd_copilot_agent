Personalized Coverage Template - Store

DescriptionThis method creates a specific personalized coverage template for the current product group.
Supported Action TypeStandard
ConstraintsEach product group must have a customized XSLT that must be created to both store and apply the personalized templates which uses the specific B-tags for the coverages. Also, there must be occurences with coverages attached for this method. Minimum checks for coverage attachment entities should be configured.
Suggested DependenciesNone
NotesThis method can be applied using applyPCDtemplate on a new quote/application.

Attributes

None
