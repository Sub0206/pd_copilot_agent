Sync Pending Customer Changes

Description

Causes any pending customer changes in the current policy transaction to be synced and committed out to the Adaptik Customer tables making them available to all other processes.

If the transaction in context is an OOS transaction, has an OOS Completion Code of O indicating that an OOS issuance has been started, and has pending replacement or carry-forward transactions associated with  it, any of those that replace previously issued transactions or represent a later-term carry-forward transaction will also be synched out to the Customer tables in the same fashion by the method.  Replacements for unissued transactions will not be synched, and their changes will remain pending.  Any identified replacement and carry-forward transactions will be processed in date order to ensure that the changes get applied in the correct date context.


Invoking this method will update the Adaptik Customer tables, and remove the pending status of the customer changes from the impacted transaction(s).  Any pending change records will be applied to the base Adaptik Customer tables using the correct time dimensioning and will be deleted from the pending tables.
Supported Action TypeStandard
ConstraintsMust be executed from within a policy transaction context.
Suggested DependenciesNone
Notes

The changes made by this method will not automatically commit to the database.  They will be subject to the commit/rollback settings of an Outcome like any other Action Step changes.


This method must be included in the Action that issues any OOS replacement transactions to ensure that any pending changes are committed as part of the issuance process.
