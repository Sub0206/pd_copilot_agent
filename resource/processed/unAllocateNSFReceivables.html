CoreSuite NAPC : unAllocateNSFReceivables

Created by Former user on Oct 25, 2019

Unallocate Receivables for NSF Processing

DescriptionThis method will update the related Remittance and its related Receivables based on its existing allocations (identified using the  targetMCID, targetCTID, targetVersion, and targetCID attributes) using the sourceAmtQtag value. The negated value from the sourceAmtQtag will be used to update the receivablePaidAmtQTag.  All the allocations on the Remittance are reversed.
Supported Action TypeView Action 
ConstraintsMust be executed within an Allocation Template.
Suggested DependenciesNone
NotesNone


XML Usage

Generate from Detail View

Attributes

There will be sixteen Attributes required for this method.  This first four Attributes will be always be MC-ID, CT-ID, Version, and C-ID which will identify the target receivable occurrence,  The next nine Attributes will be Qtags that will identify the receivable amounts of what has already been paid and the balance of what’s left and the source Remittance amount that will be used to update the Receivable amount paid, the Remittance Applied amount and Remittance remaining amount, and the reversal code, reversal time stamp on the Allocation occurrence, the reversal CID of the linked reversed occurrence, and the allocation status code.  The last three Attributes will be the Interface that will have the Views with the Attribute Qtags, to update the Receivable Parent View of the Allocation Entity and the Child Allocation Entity View to reverse the allocations of the target Remittance.
