Update Installment Lines

Description

This method will process an algorithm that will update the installment schedule information for a given policy. 

Specifically, the missing lines will be added (only applicable if the Installment Equalizer is set to Y) and the Installment Due Date will be added for each line

Supported Action TypeStandard
Constraints

Must be executed from within the Sapiens Billing System

Suggested DependenciesNone
NotesNone

Accept XML for Update

REGEN_REC_TYPE

Optional

“U” (Unbilled) or “B” (Billed)

Text

This is an optional attribute which is configured for the method when pay plan change or policy transfer are being processed.

This Attribute determines the logic used to recreate the installment schedule for the receivable generation.  If “B” is set, the Transaction Process Date is used to determines the billed immediate installments, otherwise if “U” is selected the Transfer Process Date is used to determine the new installment schedule for installments that meet the bill immediate criteria.

The default value is “B”, which is used if the Attribute is missing or does not contain a valid value.

UPD_VALID_DUEDATE

Optional

“E” (Effective Date
“N” (Next Installment)

Text

This Attribute is set to be optional and will instruct the code how to update the Due Date when it is calcaulted to be before the policy effective date.  There are two valid values for this Attribute, the code will either set the date to be the policy effective date (“E”) or the next billable installment (“N”).
The validation will always be processed, regardless if the Attribute is present or not, so if the attribute is missing the default behavior is to set the date to the policy effective date.
