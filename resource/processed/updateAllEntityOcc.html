Update All Entity Occurrences

DescriptionThis method will update the answer value for the same question or questions on all occurrences of an entity within an action step.

This method allows the configurator to specify a value for use in updating one or more questions across all occurrences of the target entity. For example, an indicator can be reset on all vehicles on a policy if the rating state changes forcing configured processing for each vehicle to be performed again based upon the updated state.

When used, the method will update the specified questions with the corresponding configured values on all occurrences of the entity across the policy transaction.

Updates made using this method will also perform standard View Item processing such as answer options, range checks, remedies, etc.
Supported Action TypeStandard
ConstraintsNone
Suggested DependenciesNone

XML Usage

None

Attributes

The following attributes are required by the method:
BTAGThe Entity tag for the entity to be updated (ex: 30005)
VTAGThe code for the View to be used to process the update. Must be a Detail or Updatable List View type. (ex: CPOL_ERR_UPD)
Question/Value pair(s)
Repeated as necessary		In the Code, the question identifier in the format Q_30005_1 must be specified.

The Value is the value to be used to update the specified question. Special answer values "DEFAULT", "CurrentDate()", or "CurrentDateTime()" are supported. DEFAULT will use the configured Defualt value form the Questions View Item in the View identified by the VTAG. If the Value is "CurrentDate()", or "CurrentDateTime()" the current date or timestamp is used to create the answer value. Otherwise, the value specified is used as the value to set in the Question's answer. if the Question has Answer Options, the value specified should be the Code value for the correct Answer Option.

This attribute can repeat to allow any number of questions to be updated in a single Step.

Return Codes

Return CodeDescription
1Update successful
2Update Successful, remedies applied
3No occurrences found. No update performed.
4Failure - No MC, CT, Version in context
5Unspecified failure (cannot update DB, etc.)
-1Unspecified Failure
