CoreSuite NAPC : updateQuestionValue

Created by Former user, last modified on Dec 05, 2019

Update Question Value (Detail View Only)

DescriptionUpdates one or more question values within a detail view in context with the answers specified. Both the questions and answers are specified in the attributes.

This method updates question answers within a detail view with the values specified as attributes. Each attribute will give the Q-tag as the code (format Q_#####_#) with the answer value to be applied in the Value attribute.

This method will not create answers. The question must be applicable in the View or the method does nothing.
Supported Action TypeView Action
ConstraintsMust be executed from within a Policy Transaction context.
Can only be used in a View Action.
Suggested DependenciesNone
NotesNone


XML Usage

None

Attributes

Each Attribute specifies the question to be set by Q-Tag and the value to be applied.
Seq #CodeValueTypeDescription
10QTag Value
(format Q_#####_#)		Specific answer value or
"CurrentDate()"

Policy level questions may also be used (Q_30000_##).		TextIdentifies the policy question to be updated and specifies the value to set it to.
(repeat attribute for each question value to be set).

In the Code, the question identifier in the format Q_30005_1 must be specified.

If the Value is "CurrentDate()", the current date is used to create the answer value.

Otherwise, the value specified is used as the value to set in the answer. if the Question has Answer Options, the value specified should be the Code value for the correct Answer Option.
