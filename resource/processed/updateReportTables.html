CoreSuite NAPC : updateReportTables

Created by Jagadish Rotti, last modified on May 15, 2023

Update Report Tables

Description

This method will write the current occurrence values to the reporting tables.

Supported Action Type

Standard Action and Action Macro.

Constraints

Must be executed from within a Transaction context.

Suggested Dependencies

None.

Notes

It is recommended to set the application property “autoUpdateReportTables” to “M” (Manual) since this is intended to take over control of report table persistence..

 XML Usage

None

Attributes

None

Return Codes

Description

Success

-1
