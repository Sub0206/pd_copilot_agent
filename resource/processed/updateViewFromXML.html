Update View From XML

Description  

This internal method is introduced to update the view by passing the XML.

XML contains QTag and value as content.

Step1: Structured search triggered with the new query id REC_SEARCH. The XSLs used to construct the request and response are fwdReceivablePWSearchRequest.xsl, bwdReceivablePWSearchResponseTEMP.xsl

Step2:  As Part of this method calls the fwdReceivableUpdateView.xsl and passes the input xml and gets the receivable amount to update the view.

Supported Action Type 

Standard 

Constraints  

Must be executed from within the Billing Pro System 

Suggested Dependencies  

None  

Notes  

None 

 

Attributes

INPUT_XML   the xml from which the remit batch search results are taken and updated in the view
