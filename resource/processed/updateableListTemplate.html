CoreSuite NAPC : updateableListTemplate

Created by Susan Wilson, last modified on 20 Nov, 2019

 

 

 

The Standard Updateable List Properties are defined below:
Property ParameterUsagePossible ValuesDescriptionComments
presentationTypeRequiredUpdateableList
Example: 
presentationType=UpdateableList		Provides the Presentation type that is being instantiated 
ViewNameRequiredValid Updateable List View V-Tag
Example:
ViewName=scheduleUPD		Provides the Updateable List View that will be used to supply the presentation information for the presentation type. 
deleteOnRowIndOptionalY, N (default)Indicates if the Delete Row Action should be included as a column within the list rather than below the list. 

displayEmptyRow

Optional

Y,N

Example:
displayEmptyRow=N 

Indicates if the initial rendering of the list should show an empty row to the user or suppress the empty row and only show the header information of the list.

Default = Y		 
synchronizeTargetOptional

synchronizeTarget =synchronizeFormsProperties

Indicates the properties file to be used to instantiate the Synchronize overlay.

Required = No (by default)

Required = Yes, if there is a Synchronize Transaction Version button

wrapHeaderTextOptional

Y, N (Default)

Example:

wrapHeaderText=Y		When set to Y, the text within the Header row of a list should be wrapped.  When set to N, the "..." notation will be used to denote that there is more text than can fit in the header cell and the mouse over will be provided to show the full text. 
wrapRowTextOptional

Y, N (Default)

Example:

wrapRowText=Y		When set to Y, the text within the row of a list should be wrapped.  When set to N, the "..." notation will be used to denote that there is more text than can fit in the row cell and the mouse over will be provided to show the full text.
NOTE: This will only occur if there is no control being shown for this field by setting the Protected Control Mode to be ‘No Control’.		 
enableFilteringOptional

Y, N (Default)

Example:

enableFiltering=Y

Indicates if the filter row should be enabled or disabled.  When property is present and set to N, the filter row will be hidden from the user.

 
enableSortingOptional

Y, N (Default)

Example:

enableSorting=Y		Indicates if the Updateable List will allow the user to sort the rows on the client.  When the property is not present or set to Y, then sorting will be disabled on the client 
scrollingEnabledOptional

Y (Default), N

Example:
scrollingEnabled=Y 

When set to Y and the number of occurrences for the entity is less than beginPagingThreshold, then the updateable list should be in scrolling mode.  If set to N, then the list is always shown in paging mode.  Also indicates when filtering and sorting functionality is performed on the server (paging) vs. on the client (scrolling). 

Default = Y
beginPagingThresholdOptional

Whole Number

Example:
beginPagingThreshold=50

Indicates the number of occurrences for the entity before paging is enabled (greater than or equal to) when scrollingEnabled=Y.  Note that the maximum number this property can contain is 100.  An application exception is given to the user if a higher number is specified.

Default = 25 if scrollingEnabled=Y
pageSizeOptional

Whole Number

Example:
pageSize=15 

Indicates the number of occurrences that should be shown inside of each "page".  If the number of rows is less than the page size and scrollingEnabled=N, then the paging controls will be suppressed from view as there are no additional "pages" of occurrences to navigate to.

Default = 10
enableRowNumberingOptional

Y, N (Default)

Example:
enableRowNumbering=Y 

Indicates if a row number should be displayed on each row of the updateable list.  

Default=N
