Void Disbursement

DescriptionThis method will update the related Entity (identified using the targetMCID, targetVersion, and targetCID attributes) using the sourcePaidAmtQtag value.  The targetPaidAmtQtag is decreased using the sourcePaidAmtQtag and the current date is used to update voidIndQTAG.  An Interface will hold the Views of all the entities that have questions being updated.
Supported Action TypeView Action
ConstraintsMust be executed within an Allocation Template
Suggested DependenciesIf Allocation type is not equal to type Receivable.
NotesNone


XML Usage

Generate from Detail View

Attributes

There will be ten Attributes required for this method.  This first four Attributes will always be MC-ID, CT-ID, Version, and C-ID.  The next four Attributes will be pointing to the QTAGS used in updating the amounts and dates on the Parent Source and Target entities. The last two Attributes will be the Interface that will have the Views with the Attribute Qtags, Receivable XML View to update the Receivable amounts and the Parent View Tag of the Allocation Entity.
